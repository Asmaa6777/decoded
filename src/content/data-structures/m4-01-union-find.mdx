# Union-Find

Are these two computers on the same network? Are these two pixels part of the same blob? Would adding this road create a loop? Each is the question "are x and y in the same group?", asked while groups keep merging. Union-find answers it in time so close to constant that no real program can tell the difference, with a parent array and two small tricks.

## The interface

A **disjoint-set** structure (also called **union-find**) keeps $n$ elements split into groups that never overlap:

- **find(x)**: which group is x in? Returns a representative element that names the group.
- **union(x, y)**: merge x's group and y's group into one.

Two elements are in the same group exactly when `find(x) == find(y)`. "Is in the same group as" is an [equivalence relation](/courses/discrete-mathematics/relations#equivalence-relations), and the groups are its equivalence classes.

## A forest in an array

Store each group as a tree pointing **upwards**: every element has a **parent**, and the root, whose parent is itself, is the group's representative. The whole structure is one array, `parent[x]`.

- **find(x)** follows parents up to the root.
- **union(x, y)** finds both roots and makes one the parent of the other.

Done naively, the trees can grow into long chains and find becomes O(n). Two tricks fix that:

1. **Union by rank**: hang the **shorter** tree under the taller one's root, never the other way round. Each root keeps a **rank**, an upper bound on its tree's height. Trees then stay O(log n) tall.
2. **Path compression**: after find(x) reaches the root, point **every node on the path** straight at the root. The next find from any of them is one step.

Union a few pairs, then switch to **Find** and click a deep node. Or press **join everything** and find from the bottom.

<UnionFindLab />

With both tricks, any sequence of $m$ operations on $n$ elements takes $O(m\,\alpha(n))$ time, where $\alpha$ is the **inverse Ackermann function**. It grows so slowly that $\alpha(n) \le 4$ for any $n$ that could fit in the universe. In practice, every operation is constant time.

```python
class DisjointSet:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        root = x
        while self.parent[root] != root:
            root = self.parent[root]
        while self.parent[x] != root:            # path compression
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                          # already together
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra                      # shorter under taller
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True

ds = DisjointSet(6)
ds.union(0, 1)
ds.union(2, 3)
ds.union(1, 3)
print(ds.find(0) == ds.find(2))  # True
print(ds.find(4) == ds.find(5))  # False
print(ds.union(0, 3))  # False
```

```java
public class Main {
    static int[] parent, rank;

    static int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);   // path compression
        return parent[x];
    }

    static boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (rank[ra] < rank[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;                                    // shorter under taller
        if (rank[ra] == rank[rb]) rank[ra]++;
        return true;
    }

    public static void main(String[] args) {
        int n = 6;
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        union(0, 1);
        union(2, 3);
        union(1, 3);
        System.out.println(find(0) == find(2));  // true
        System.out.println(find(4) == find(5));  // false
        System.out.println(union(0, 3));  // false
    }
}
```

```cpp
#include <iostream>
#include <numeric>
#include <utility>
#include <vector>

struct DisjointSet {
    std::vector<int> parent, rank;
    explicit DisjointSet(int n) : parent(n), rank(n, 0) { std::iota(parent.begin(), parent.end(), 0); }

    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }   // path compression

    bool unite(int a, int b) {       // "union" is a C++ keyword
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (rank[ra] < rank[rb]) std::swap(ra, rb);
        parent[rb] = ra;
        if (rank[ra] == rank[rb]) rank[ra]++;
        return true;
    }
};

int main() {
    DisjointSet ds(6);
    ds.unite(0, 1);
    ds.unite(2, 3);
    ds.unite(1, 3);
    std::cout << std::boolalpha << (ds.find(0) == ds.find(2)) << "\n";  // true
    std::cout << (ds.find(4) == ds.find(5)) << "\n";  // false
    std::cout << ds.unite(0, 3) << "\n";  // false
}
```

<Callout tone="orange" label="Union-find can't split groups">
It merges, and only merges. If your groups need to come apart again, for example when a network link goes down, union-find can't undo a union cheaply; you'd rebuild it or reach for a different structure.
</Callout>

## Kruskal's algorithm

The classic use: [Kruskal's algorithm](/courses/advanced-algorithms/minimum-spanning-trees#kruskals-algorithm) builds a minimum spanning tree by taking edges from cheapest to most expensive, and keeping an edge only if its two ends are in **different** groups. "Different groups" is one find each, and keeping the edge is one union. That's why `union` returning `False` above is useful: it means "this edge would make a cycle".
