# Main Memory Performance

Every computer architecture faces the **memory wall**: the widening speed gap between the processor and main memory. Processor pipelines have grown hundreds of times faster over recent decades, while dynamic RAM access times have improved far more slowly. A modern CPU core can finish hundreds of operations in the time it takes one request to reach main memory and return. Preventing the CPU from sitting idle takes careful work across memory organization, cell design, bus timing, and bank interleaving.

You have seen [what a memory unit is built from](/courses/logic-design/memory-unit) and [where it sits in the memory hierarchy](/courses/computer-organization/memory-hierarchy). This lesson looks at what makes memory fast or slow: how SRAM and DRAM store bits, how chips combine into wider arrays, and how interleaving keeps data moving on every bus cycle.

## Memory Technologies: SRAM and DRAM

Semiconductor memory comes in two main types, separated by whether the storage cells need constant electrical refreshing.

### Static RAM (SRAM)

A **static random-access memory** (SRAM) cell stores each bit in a two-state latch made from two cross-coupled inverters. The standard design uses six CMOS transistors (a 6T cell).

The two inverters connect in a loop: the output of each inverter drives the input of the other. This feedback locks the internal storage nodes into one of two stable states: high ($V_{DD}$) or low (Ground). Two nMOS access transistors connect these nodes to a pair of complementary data wires called the **Bit Line** ($BL$) and **Bit Line Bar** ($\overline{BL}$). When the row select wire, called the **Word Line**, goes high, both access transistors turn on and connect the cell to the bit lines for reading or writing.

1. **High speed**: An access takes between 0.5 and 2.5 nanoseconds because reads and writes only need to charge or discharge gate capacitance.
2. **Persistence**: The cell retains its stored bit as long as power is connected. It needs no refresh circuitry.
3. **Low density and high cost**: Six transistors per bit take up substantial silicon area. SRAM chips hold far fewer bits per square millimeter than DRAM chips and cost more per gigabyte.

Because SRAM is fast but space-hungry, processors reserve it for on-chip caches: L1, L2, and L3.

### Dynamic RAM (DRAM)

A **dynamic random-access memory** (DRAM) cell stores a bit as charge on a tiny capacitor, accessed through a single transistor (a 1T-1C cell).

The transistor gate connects to the **Word Line** (row select), one terminal connects to the **Bit Line** (column data), and the other connects to the storage capacitor (often only 20 to 30 femtofarads).

1. **High density**: With only one transistor and one capacitor per bit, billions of cells fit on a single chip. This makes DRAM economical for main memory.
2. **Capacitor leakage and refresh**: Charge leaks through the silicon substrate within milliseconds. To prevent data loss, the memory controller issues periodic **refresh** commands (reading and rewriting each row about every 64 milliseconds). The memory is called dynamic because its stored state decays over time.
3. **Destructive read**: Reading a cell drains it. The tiny capacitor charge ($Q = C V$) shares itself with the larger capacitance of the long bit line wire, shifting the wire voltage by only a few tens of millivolts. A sensitive **sense amplifier** detects this small shift, pulls the line to full voltage ($V_{DD}$ or Ground), and writes the value back to the capacitor to restore the original charge before closing the row.
4. **The row buffer**: When a word line activates a row of cells, the sense amplifiers copy an entire row of data (thousands of bits, often called a DRAM page) into an on-chip latch array called the **row buffer**. Later reads from that same row come straight from the row buffer, skipping the row activation delay.

Non-volatile semiconductor storage includes **read-only memory** (ROM), electrically erasable programmable ROM (EEPROM), and **flash memory**. Flash memory stores charge on floating gates or charge traps that hold data without power. NAND flash provides high density for solid-state drives (SSDs), while NOR flash allows random byte-level reads for bootloaders.

## Key Performance Metrics: Latency and Bandwidth

Three metrics define memory subsystem performance:

1. **Access time ($t_{AC}$)**: The delay between the processor placing an address and read command on the bus and valid data appearing on the data pins.
2. **Cycle time ($t_{CYC}$)**: The minimum time needed between starting one access and starting the next. For SRAM, cycle time matches access time closely. For DRAM, cycle time is much longer than access time because the array has to precharge its bit lines and recharge the capacitors after every read.
3. **Bandwidth**: The rate at which data moves across the bus, measured in megabytes or gigabytes per second:

$$
\text{Bandwidth} = \frac{\text{Bytes per transfer}}{\text{Cycle time}} = \text{Bus Width (bytes)} \times \text{Bus Frequency} \times \text{Transfers per cycle}
$$

<Callout tone="orange" label="Confusing access time with cycle time">
It is easy to assume that once memory returns data ($t_{AC}$), it can accept the next command immediately. In DRAM, cycle time $t_{CYC}$ is much longer than access time because the bank must precharge bit lines and restore capacitor charge before opening another row. Sending another request before $t_{CYC}$ completes leads to corrupt data.
</Callout>

For example, a system with a 64-bit wide data bus (8 bytes) operating with a memory cycle time of 10 nanoseconds yields:

$$
\text{Bandwidth} = \frac{8\text{ bytes}}{10 \times 10^{-9}\text{ s}} = 800\text{ MB/s}
$$

### DRAM Timing Parameters

Modern DRAM controllers coordinate transfers with timing parameters measured in memory clock cycles:

- **Row Address to Column Address Delay ($t_{RCD}$)**: The cycles needed to activate a row in the array and latch it into the row buffer before issuing a column command.
- **Column Address Strobe Latency ($t_{CL}$ or CAS Latency)**: The delay in clock cycles between sending a column address and the first data word appearing on the data pins.
- **Row Precharge Time ($t_{RP}$)**: The time needed to precharge the bit lines and close an active row so another row in the same bank can open.
- **Row Active Time ($t_{RAS}$)**: The minimum time a row must stay open so the sense amplifiers can fully recharge the capacitors.

This creates two access paths:
- **Row buffer hit (Page hit)**: The requested data is already in the open row buffer. The access needs only CAS latency: $t_{\text{access}} = t_{CL}$.
- **Row buffer conflict (Page miss)**: The address is in a different row of the same bank. The controller must precharge the old row, activate the new one, and read the column: $t_{\text{access}} = t_{RP} + t_{RCD} + t_{CL}$.

When memory is sold as **DDR4-3200 16-18-18-38**, those four numbers represent $t_{CL}$, $t_{RCD}$, $t_{RP}$, and $t_{RAS}$ in clock cycles at a 1600 MHz bus clock.

## Memory Organization: Sizing and Chip Arrays

Individual memory chips have fixed word lengths and capacities. To build a larger system, designers connect multiple chips into an array.

To build a memory of size $M \times N$ ($M$ words of $N$ bits each) using smaller chips of size $K \times W$ ($K$ words of $W$ bits each):

1. **Expanding word length**: When the word width $N$ is wider than the chip width $W$, place $N / W$ chips side by side. Their address lines and control wires connect in parallel to the bus. Each chip provides $W$ bits toward the total $N$-bit data word.
2. **Expanding word capacity**: When the total words $M$ exceed the chip capacity $K$, create $M / K$ separate banks. A decoder reads the higher address bits to drive the active-low chip select ($\overline{CS}$) pin of the target bank. The lower address bits connect in parallel to every chip.

<Callout tone="orange" label="Address pin confusion in memory expansion">
When wiring chips into an array, it is easy to wonder whether high or low address bits go to the chip pins. The chip pins must receive the continuous lower address bits ($A_{k-1} \dots A_0$) so each chip holds a contiguous block of addresses. The higher address bits ($A_{A-1} \dots A_k$) feed the bank select decoder to choose which bank is active. Swapping them scatters adjacent bytes across physical chips.
</Callout>

<Callout tone="sky" label="Address bus splitting">
For an address bus of $A$ bits accessing a byte-organized memory:
- If each chip contains $2^k$ locations, $k$ address pins connect directly to all chips ($A_{k-1} \dots A_0$).
- The remaining $A - k$ high-order address bits ($A_{A-1} \dots A_k$) feed a $1\text{-of-}2^{A-k}$ binary decoder. Each decoder output connects to the chip select input ($\overline{CS}$) of one memory bank.
</Callout>

## Memory Interleaving

When a single memory bank takes a read, the entire bank stays busy for the full cycle time $t_{CYC}$. If the cycle time is 40 ns and the bus transfer time $t_B$ is only 10 ns, the bus sits idle for 30 ns while the bank precharges and recovers.

**Memory interleaving** divides memory into $M$ independent banks. Each bank has its own address buffer, row and column decoders, and sense amplifiers. Distributing addresses across multiple banks allows consecutive requests to start in different banks before earlier banks finish recovering.

### Low-Order Interleaving

In **low-order interleaving** (consecutive interleaving), the least significant bits of the memory address select the bank:

$$
\text{Bank Index} = \text{Address} \bmod M
$$

The higher-order address bits select the memory word within the chosen bank:

| Address | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| Bank | 0 | 1 | 2 | 3 | 0 | 1 | 2 | 3 |

When the CPU reads a sequence of consecutive addresses (such as fetching instructions or filling a cache line), it sends Address 0 to Bank 0. On the next bus clock cycle, it sends Address 1 to Bank 1, followed by Address 2 to Bank 2, and Address 3 to Bank 3.

<InterleaveLab />

If the degree of interleaving $M$ satisfies $M \ge t_{CYC} / t_B$, memory throughput achieves the theoretical limit of the memory bus: one data word delivered every bus transfer cycle.

<Callout tone="orange" label="The stride conflict trap">
Low-order interleaving speeds up sequential reads. But if a program reads an array with a stride that is a multiple of $M$ (such as reading down a column of a matrix stored by rows), every access lands in the same bank. For example, in a 4-bank system ($M = 4$) with a stride of 4, indices $0, 4, 8, 12, \dots$ all calculate:
$$
0 \bmod 4 = 0, \quad 4 \bmod 4 = 0, \quad 8 \bmod 4 = 0, \quad 12 \bmod 4 = 0
$$
Every read routes to Bank 0, leaving Banks 1, 2, and 3 idle. The accesses queue up, forcing the CPU to wait a full recovery cycle $t_{CYC}$ between transfers.
</Callout>

### High-Order Interleaving

In **high-order interleaving** (modular interleaving), the most significant address bits select the bank:

$$
\text{Bank Index} = \lfloor \text{Address} / K \rfloor
$$

All consecutive addresses up to bank capacity $K$ reside within Bank 0, the next block of $K$ addresses resides in Bank 1, and so on. High-order interleaving provides no speedup for sequential burst transfers by a single processor. However, in multiprocessor or multi-channel systems, high-order interleaving allows multiple processors or direct memory access (DMA) channels to operate on separate programs or memory buffers simultaneously without bank contention.

## Modern High-Performance DRAM Innovations

Modern memory standards increase bandwidth with several design changes:

1. **Synchronous DRAM (SDRAM)**: Older DRAM waited on control signal changes. SDRAM latches addresses and commands on the rising edge of the system bus clock, keeping memory in lockstep with the processor.
2. **Burst Mode**: After sending an initial row and column address, the memory controller leaves the row open in the row buffer and streams a burst of 4, 8, or 16 consecutive words on consecutive clock cycles without sending new addresses.
3. **Double Data Rate (DDR)**: DDR SDRAM transfers data on both the rising and falling edges of the clock signal, doubling data throughput without raising clock frequency. Later generations (DDR2 through DDR5) increase prefetch buffer depths (from 2n to 16n) and raise bus frequencies.
4. **Dual In-line Memory Modules (DIMMs)**: Main memory is mounted on circuit boards called **DIMMs**, with memory chips on both sides and separate electrical contacts on each side, giving a standard 64-bit wide data bus to the motherboard.
5. **Multi-Channel Architecture**: Motherboards provide independent 64-bit memory channels. Dual-channel memory controllers talk to two distinct DIMM slots at once across a combined 128-bit interface, doubling peak bandwidth.

<Callout tone="orange" label="Confusing transfer rate (MT/s) with clock frequency">
A DDR4-3200 memory module does not run at an internal clock frequency of 3200 MHz. Because DDR transfers data on both the rising and falling edges of the clock signal, the memory I/O bus clock runs at 1600 MHz to achieve 3200 MegaTransfers per second (3200 MT/s). The internal DRAM core runs slower still (typically 200 to 400 MHz), using an 8n prefetch buffer to feed the faster bus.
</Callout>

<Callout tone="violet" label="Why dual-channel memory matters">
A CPU with integrated graphics relies on system RAM to hold video frames. A single 64-bit DDR4 channel at 3200 MT/s gives 25.6 GB/s of bandwidth. Running two DIMMs in dual-channel mode widens the bus to 128 bits, providing 51.2 GB/s and keeping the graphics pipeline from stalling on memory.
</Callout>

<Callout tone="mint" label="Key takeaway">
Main memory performance balances access latency against burst bandwidth. SRAM offers sub-nanosecond access speeds for caches, while DRAM delivers dense, low-cost capacity for main memory. Low-order interleaving hides DRAM cycle recovery time by pipelining transfers across independent banks, matching bus capacity for sequential workloads.
</Callout>

## Exam-Style Practice

<ModelAnswer title="Problem 1: Memory chip sizing and address decoding">
A digital computer requires a main memory capacity of $512\text{ KB}$ with a word size of 32 bits (4 bytes per word). The system is built using semiconductor SRAM chips of size $128\text{K} \times 8$ bits.

1. How many total $128\text{K} \times 8$ memory chips are required?
2. How many chips are placed in parallel to form a single 32-bit word?
3. How many distinct banks (rows of chips) are formed?
4. Assuming the memory is byte-addressable with a 19-bit address bus ($A_{18} \dots A_0$ where $2^{19}\text{ bytes} = 512\text{ KB}$), determine how the address bits are partitioned between the chip address inputs and the bank decoder.

---

**Solution:**

**Part 1: Total chips required:**
- Total required memory capacity: $512\text{ KB} = 512 \times 1024\text{ bytes} = 524{,}288\text{ bytes}$.
- Word length: 32 bits = 4 bytes per word.
- Number of words required: $524{,}288\text{ bytes} / 4\text{ bytes/word} = 131{,}072\text{ words} = 128\text{K words}$.
- Storage capacity of one chip: $128\text{K} \times 8\text{ bits} = 128\text{ KB}$.
- Total chips required:
  $$
  \text{Total chips} = \frac{\text{Total Capacity}}{\text{Chip Capacity}} = \frac{512\text{ KB}}{128\text{ KB}} = 4\text{ chips}
  $$

**Part 2: Chips in parallel per word:**
Each memory word is 32 bits (4 bytes) wide, while each chip outputs 8 bits (1 byte):
$$
\text{Chips in parallel per word} = \frac{32\text{ bits}}{8\text{ bits per chip}} = 4\text{ chips}
$$
The 4 chips connect in parallel across data bus lines $D_{31} \dots D_0$: Chip 0 drives bits $D_7 \dots D_0$, Chip 1 drives $D_{15} \dots D_8$, Chip 2 drives $D_{23} \dots D_{16}$, and Chip 3 drives $D_{31} \dots D_{24}$.

**Part 3: Number of banks:**
$$
\text{Number of banks} = \frac{\text{Total chips}}{\text{Chips per word}} = \frac{4}{4} = 1\text{ bank}
$$
All 4 chips operate in parallel as a single bank providing $128\text{K}$ 32-bit words ($512\text{ KB}$).

**Part 4: Address bus partitioning:**
Total addressable space is $512\text{ KB} = 2^{19}\text{ bytes}$, requiring 19 address lines ($A_{18} \dots A_0$):
- **Byte Offset within Word (2 bits, $A_1 \dots A_0$)**: Because each word consists of 4 bytes, $\log_2(4) = 2$ bits select the individual byte within the 32-bit word during byte-level memory operations.
- **Chip Address Inputs (17 bits, $A_{18} \dots A_2$)**: Each chip contains $128\text{K} = 2^{17}$ addressable locations. Therefore, the 17 address bits $A_{18} \dots A_2$ connect directly to the 17 address pins of all 4 chips in parallel.
- **Bank Select**: Because one bank covers the entire $512\text{ KB}$ space, the system needs no external bank decoder. The active-low chip select pins ($\overline{CS}$) of all 4 chips are asserted simultaneously whenever a valid memory request occurs.
</ModelAnswer>

<ModelAnswer title="Problem 2: Interleaved memory bandwidth and timing analysis">
A processor requests a burst of 8 consecutive 64-bit words from main memory.
The memory subsystem has the following timing parameters:
- Memory bank access time ($t_{AC}$): 30 ns
- Memory bank cycle time ($t_{CYC}$): 50 ns
- Memory bus transfer time ($t_B$): 10 ns (the time required to transmit one 64-bit word across the bus)

Calculate the total time required to service the 8-word transfer under two designs:
1. Design A: A conventional single-bank memory system.
2. Design B: A 4-bank low-order interleaved memory system.
3. Determine the effective memory bandwidth (in megabytes per second) achieved by each design for this 8-word burst.

---

**Solution:**

**Part 1: Design A (Single-Bank Memory):**
In a single-bank system, all memory accesses must route through the same memory bank. After initiating a read, the bank is busy for its full cycle time ($t_{CYC} = 50\text{ ns}$) before it can accept the next address:
- Access 1 starts at $t = 0\text{ ns}$. Data is ready at $t = 30\text{ ns}$ and transfers on the bus until $t = 40\text{ ns}$. The bank finishes recovery at $t = 50\text{ ns}$.
- Access 2 starts at $t = 50\text{ ns}$, transfers data from $t = 80\text{ ns}$ to $t = 90\text{ ns}$, and finishes recovery at $t = 100\text{ ns}$.
- Accesses 1 through 7 each require a full cycle time $t_{CYC} = 50\text{ ns}$. Access 8 initiates at $t = 7 \times 50\text{ ns} = 350\text{ ns}$, outputs data at $350 + 30 = 380\text{ ns}$, and finishes bus transfer at $380 + 10 = 390\text{ ns}$.

Total time for 8 words:
$$
T_{\text{single}} = 7 \times t_{CYC} + t_{AC} + t_B = 7 \times 50\text{ ns} + 30\text{ ns} + 10\text{ ns} = 350 + 40 = 390\text{ ns}
$$

**Part 2: Design B (4-Bank Low-Order Interleaved Memory):**
In a 4-bank low-order interleaved system:
- Words 0, 1, 2, 3 map to Banks 0, 1, 2, 3 respectively. Words 4, 5, 6, 7 map to Banks 0, 1, 2, 3 in round-robin order.
- The memory controller issues consecutive requests across the bus every $t_B = 10\text{ ns}$:
  - $t = 0\text{ ns}$: Word 0 requested from Bank 0.
  - $t = 10\text{ ns}$: Word 1 requested from Bank 1.
  - $t = 20\text{ ns}$: Word 2 requested from Bank 2.
  - $t = 30\text{ ns}$: Word 3 requested from Bank 3.
- Data returns from the banks and streams continuously on the bus:
  - Bank 0 outputs Word 0 at $t = 30\text{ ns}$, bus transfer completes at $t = 40\text{ ns}$. Bank 0 finishes recovery at $t = 0 + 50 = 50\text{ ns}$.
  - Bank 1 outputs Word 1 at $t = 40\text{ ns}$, bus transfer completes at $t = 50\text{ ns}$.
  - Bank 2 outputs Word 2 at $t = 50\text{ ns}$, bus transfer completes at $t = 60\text{ ns}$.
  - Bank 3 outputs Word 3 at $t = 60\text{ ns}$, bus transfer completes at $t = 70\text{ ns}$.
- At $t = 40\text{ ns}$, the controller is ready to request Word 4 from Bank 0. However, Bank 0 requires a 50 ns recovery cycle ($t = 0$ to $t = 50\text{ ns}$). Thus, Bank 0 initiates the request for Word 4 exactly at $t = 50\text{ ns}$.
- Data delivery for the second wave of words:
  - Bank 0 outputs Word 4 at $50 + 30 = 80\text{ ns}$, bus transfer completes at $t = 90\text{ ns}$.
  - Bank 1 outputs Word 5 at $60 + 30 = 90\text{ ns}$, bus transfer completes at $t = 100\text{ ns}$.
  - Bank 2 outputs Word 6 at $70 + 30 = 100\text{ ns}$, bus transfer completes at $t = 110\text{ ns}$.
  - Bank 3 outputs Word 7 at $80 + 30 = 110\text{ ns}$, bus transfer completes at $t = 120\text{ ns}$.

Total time to complete the 8-word transfer:
$$
T_{\text{interleaved}} = 120\text{ ns}
$$
Interleaving achieves a $390 / 120 = 3.25\times$ speedup over the single-bank system.

**Part 3: Effective Memory Bandwidth:**
Total data transferred = 8 words $\times 8\text{ bytes per word} = 64\text{ bytes}$.

- For Design A:
  $$
  \text{Bandwidth}_{\text{single}} = \frac{64\text{ bytes}}{390 \times 10^{-9}\text{ s}} \approx 164.1\text{ MB/s}
  $$
- For Design B:
  $$
  \text{Bandwidth}_{\text{interleaved}} = \frac{64\text{ bytes}}{120 \times 10^{-9}\text{ s}} \approx 533.3\text{ MB/s}
  $$
</ModelAnswer>
