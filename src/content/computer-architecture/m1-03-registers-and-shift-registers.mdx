# Registers and Shift Registers

A single flip-flop stores one bit. Grouping multiple flip-flops with a shared clock line forms a **register**, a storage block capable of capturing and presenting an entire multi-bit binary word in a single clock cycle.

## The parallel-load register

In a digital computer, a register must maintain its value across clock cycles until software commands an update. Directly gating or switching off the CPU clock line can introduce timing skews and electrical glitches. Hardware designers therefore route the system clock continuously to all flip-flops and control loading using a **LOAD** control line with 2-to-1 multiplexers:

* **When $\text{LOAD} = 0$**: The multiplexer routes each flip-flop's own output $Q$ back into its data input $D$. On every clock tick, the flip-flop simply reloads its current state, maintaining its stored data indefinitely.
* **When $\text{LOAD} = 1$**: The multiplexer selects the new external data input wire ($I_i$). On the rising clock edge, all flip-flops latch the new parallel binary word simultaneously.
* **Asynchronous Clear ($\overline{\text{CLR}}$)**: An active-low reset line that overrides both clock and data inputs, instantly clearing all outputs to 0.

When an assembly instruction executes `MOV AX, BX`, the processor places the contents of register BX onto the internal data bus and pulses the $\text{LOAD}$ line of register AX, latching all sixteen bits in parallel on the next clock edge.

## Shift registers

A **shift register** is a cascade of flip-flops where the output of each stage connects directly to the data input of the next stage. On each clock edge, stored bits advance by one position along the chain.

Shift direction is defined relative to bit significance:

* **Shift Right**: Bits move toward the least significant bit ($Q_{i-1} \leftarrow Q_i$). Serial data enters at the most significant bit ($Q_{n-1}$).
* **Shift Left**: Bits move toward the most significant bit ($Q_{i} \leftarrow Q_{i-1}$). Serial data enters at the least significant bit ($Q_0$).

### Cycle-by-cycle bit stream trace

Suppose a 4-bit shift register ($Q_3, Q_2, Q_1, Q_0$) begins cleared to $0000_2$, shifting right with bits entering at $Q_3$. If a serial data stream presenting bits $1, 0, 1, 1$ arrives sequentially, the register contents advance on each clock tick:

| Clock Cycle | Serial Input | $Q_3$ (MSB) | $Q_2$ | $Q_1$ | $Q_0$ (LSB) | Serial Output ($Q_0$ leaving) |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| Initial | — | 0 | 0 | 0 | 0 | 0 |
| Clock 1 | **1** | **1** | 0 | 0 | 0 | 0 |
| Clock 2 | **0** | **0** | **1** | 0 | 0 | 0 |
| Clock 3 | **1** | **1** | **0** | **1** | 0 | 0 |
| Clock 4 | **1** | **1** | **1** | **0** | **1** | 0 |

After four clock cycles, the 4-bit binary word $1101_2$ is fully assembled across the parallel outputs $Q_3..Q_0$. On clock 5, the first bit ($1$) will leave stage $Q_0$ as serial output.

## Shift register topologies

Shift registers are classified by how data enters and exits the circuit:

### 1. Serial-In, Serial-Out (SISO)

Data enters one bit per clock cycle through a single serial input pin, and leaves one bit per clock cycle from the final stage's output. For an $n$-bit shift register, a bit entering the first stage requires exactly $n$ clock cycles to emerge at the serial output. SISO registers function as digital delay lines.

### 2. Serial-In, Parallel-Out (SIPO)

Data enters one bit per clock cycle. Once $n$ bits have been shifted in, the receiving logic reads all $n$ flip-flop outputs simultaneously. SIPO registers form the foundation of serial receivers, converting incoming sequential pulses into parallel memory words.

### 3. Parallel-In, Serial-Out (PISO)

All $n$ flip-flops load a full binary word in parallel on a single clock tick using multiplexed load gates. Subsequent clock pulses shift the word out one bit at a time over a single wire. PISO registers form the core of serial transmitters.

### 4. Parallel-In, Parallel-Out (PIPO)

Bits are loaded in parallel and read in parallel. This is the architecture used by general-purpose CPU registers, such as the accumulator and instruction register.

## Real-world applications

Shift registers power fundamental hardware operations across computer architecture:

* **Serial Communication Protocols**: Peripherals communicate with computers over single-wire interfaces to minimize cable pins. Hardware transceivers, such as Universal Asynchronous Receiver-Transmitters (UART), Universal Serial Bus (USB), and Serial Peripheral Interface (SPI), use PISO registers to transmit bytes and SIPO registers to reconstruct them.
* **Arithmetic Multiplication and Division**: Shifting an unsigned binary number left by one position doubles its numerical value ($x \times 2$), while shifting right by one position halves it ($x / 2$). Processor ALUs use barrel shifters and shift registers to accelerate arithmetic multiplication and address index calculations.
