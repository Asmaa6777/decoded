# Bit Depth: How Many Shades a Pixel Holds

A pixel stores its color as a number, and a number in a computer is a fixed count of [bits](/courses/computer-organization/bits-and-bytes). The number of bits used for each pixel is called the **bit depth** (or **color depth**), measured in **bits per pixel (bpp)**. It decides how many different colors or shades the image can use. The usual kinds, 1-bit, 8-bit, 16-bit, 24-bit and 32-bit, are sometimes called the **image data types** or image color formats.

## The rule: n bits give 2ⁿ values

Each bit doubles the number of patterns. One bit has 2 patterns (0, 1). Two bits have 4 (00, 01, 10, 11). Three bits have 8. In general:

$$
\text{number of colors} = 2^{\,\text{bits per pixel}}
$$

That one formula answers most bit-depth questions:

| Bits per pixel | Colors | Usually called |
|---|---|---|
| 1 | $2^1 = 2$ | binary, monochrome |
| 2 | $2^2 = 4$ | |
| 4 | $2^4 = 16$ | |
| 8 | $2^8 = 256$ | grayscale, or indexed color |
| 16 | $2^{16} = 65{,}536$ | high color |
| 24 | $2^{24} = 16{,}777{,}216$ | true color |
| 32 | $2^{32} = 4{,}294{,}967{,}296$ combinations: 16,777,216 colors × 256 levels of transparency | true color with alpha |
| 48 | $2^{48} \approx 281$ trillion | high dynamic range (16 bits per channel) |

Early PCs climbed this table one row at a time as memory got cheaper. Each step came with a new **graphics adapter**, the card inside the computer that holds the frame buffer and sends the picture to the monitor. Each card was a standard with its own name:

| Name | Stands for | Bits per pixel | Colors at once |
|---|---|---|---|
| Monochrome | (one color on black) | 1 | 2 |
| CGA | Color Graphics Adapter | 2 | 4 |
| EGA | Enhanced Graphics Adapter | 4 | 16 |
| VGA | Video Graphics Array | 8 | 256 |
| XGA | Extended Graphics Array | 16 | 65,536 |
| SVGA | Super VGA | 24 | 16,777,216 |

Some of these names outlived the cards. "VGA" still means a 640 × 480 resolution, and the blue 15-pin monitor plug on older laptops and projectors is called a VGA port. Today almost everything uses 24 or 32 bits.

## 1-bit images: binary

With 1 bit per pixel, each pixel is 0 or 1, off or on, usually black or white. Such an image is called a **binary image** or **1-bit monochrome**. The house in the [last lesson](/courses/computer-graphics/pixels-and-the-image-grid) was one. Binary images are tiny, but they can't show shading at all. Fax machines and scanned text documents still use them, because text only needs ink or no ink.

## 8-bit images: grayscale

Give each pixel one whole [byte](/courses/computer-organization/bits-and-bytes#the-byte), 8 bits, and it can hold $2^8 = 256$ values, from 0 to 255. In a **grayscale** (or **gray-level**) image, that value is a brightness: 0 is black (no light), 255 is white (full light), and everything between is a shade of gray. A dark pixel might be 15; a bright one 240.

For example, a pixel stored as the byte `01000011` has the value

$$
0\cdot128 + 1\cdot64 + 0\cdot32 + 0\cdot16 + 0\cdot8 + 0\cdot4 + 1\cdot2 + 1\cdot1 = 67
$$

out of 255, which is a fairly dark gray. (If converting binary to decimal is new, [Number Systems](/courses/logic-design/number-systems#binary-to-decimal) walks through it.)

Each brightness has to snap to the nearest level the bits can store. With 2 bits there are only 4 levels (0, 85, 170 and 255), so a brightness of 67 is stored as level `01` and comes back as 85. With 8 bits it stays exactly 67. Those stripes in a low-depth image are called **banding**, and you'll spot them in skies of heavily compressed photos and old GIFs.

## Indexed color: 256 colors from a bigger palette

8 bits can also mean something else. In **indexed color**, the image stores a **palette**, a table of up to 256 full colors, and each pixel holds a number from 0 to 255 that says which palette entry to use. The pixel isn't a color; it's a page number in a color book. GIF files work this way, which is why a GIF can be colorful yet limited to 256 different colors at once.

## More depth costs more memory

More bits per pixel give more accurate color and smoother gradients, but every pixel gets bigger, so the whole image does too. A document of black text gains nothing from 24-bit color, so storing it at 1 bit per pixel saves a lot of space. Bigger images also take longer to send over a network, which is why images with a high bit depth are usually compressed. Choosing the depth is a trade between quality and size, and the [image size lesson](/courses/computer-graphics/image-size) puts numbers on it.

People can tell apart roughly ten million colors, which is why 24-bit true color, at about 16.7 million, is enough for almost any picture and gets called "true".
