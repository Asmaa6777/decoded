# Polynomials and Their Roots

MATLAB has no special polynomial type. A polynomial is just a row vector of its coefficients, in descending powers. So everything from the [matrix module](/courses/computational-mathematics/matrices-and-matlab) applies: a polynomial is data you can store, pass around and do arithmetic on.

## Writing one down

The polynomial

$$
p(x) = x^3 - 2x^2 - x + 2
$$

is entered as:

```matlab
p = [1 -2 -1 2];
```

Missing powers still need a place. $x^3 - 2x - 5$ has no $x^2$ term, so its vector is `[1 0 -2 -5]`, with an explicit zero.

## Roots

A **root** is a value of $x$ where $p(x) = 0$, which is where the curve crosses the x-axis. `roots` returns them as a column vector, and `poly` goes the other way:

```matlab
r = roots(p)      % -1, 2 and 1

p2 = poly(r)      % 1  -2  -1  2
```

These two are inverse functions, up to ordering, scaling and rounding error.

## Evaluating

`polyval(p, 3)` works out $p(3) = 27 - 18 - 3 + 2 = 8$. Drag the sliders and see the roots move. When the curve lifts off the axis, the real roots disappear, and they turn up again as a complex pair:

## Evaluating at a matrix

`polyvalm` puts a square matrix where $x$ was. Its powers are [matrix products](/courses/computational-mathematics/multiplying-matrices#the-rule), so $X^3$ means $X \cdot X \cdot X$, not each entry cubed. The constant term has to become a matrix as well, so it's multiplied by the [identity](/courses/computational-mathematics/multiplying-matrices#the-identity-matrix):

$$
p(x) = x^3 - 2x - 5 \quad\text{becomes}\quad p(X) = X^3 - 2X - 5I
$$

```matlab
p = [1 0 -2 -5];
X = [2 4 5; -1 0 3; 7 1 5];
Y = polyvalm(p, X)

Y =
   377   179   439
   111    81   136
   490   253   639
```

Note that this differs from `polyval(p, X)`, which evaluates the polynomial separately on each entry.

## In Python

NumPy kept MATLAB's function names and its descending coefficient order:

```python
import numpy as np

p = [1, -2, -1, 2]

print(np.round(np.sort(np.roots(p)), 6).tolist())  # [-1.0, 1.0, 2.0]
print(np.round(np.poly([-1, 2, 1]), 6).tolist())  # [1.0, -2.0, -1.0, 2.0]
print(np.polyval(p, 3))  # 8
```

`polyval` uses Horner's method, which is short enough to write in pure Python. It needs only one multiplication per coefficient:

```python
def polyval(p, x):
    result = 0
    for c in p:
        result = result * x + c
    return result

print(polyval([1, -2, -1, 2], 3))  # 8
```

## In machine learning

**Polynomial features.** Adding $x^2$ and $x^3$ as extra columns lets a linear model fit curves. The model stays linear in its weights, so the same solver works.

**Eigenvalues.** The eigenvalues of a matrix are the roots of its characteristic polynomial, and PCA ranks directions by those eigenvalues:

```python
import numpy as np

A = np.array([[2.0, 1.0], [1.0, 2.0]])
char_poly = np.poly(A)

print(np.round(char_poly, 6).tolist())  # [1.0, -4.0, 3.0]
print(np.round(np.sort(np.roots(char_poly)), 6).tolist())  # [1.0, 3.0]
```

Real libraries don't compute eigenvalues this way, because finding polynomial roots is numerically touchy. In fact, `np.roots` works the other way round: it builds a matrix and computes its eigenvalues.

**Minimising a loss.** A minimum of a smooth loss is a place where the [derivative](/courses/computational-mathematics/derivatives-and-curve-fitting#derivatives) is zero, so training looks for a root of the gradient.
