# Partial Fractions

A ratio of two polynomials can be hard to work with. Split it into a sum of simple fractions and each piece becomes easy to integrate, to invert, or to read off a system's behaviour.

## The expansion

For polynomials $b$ and $a$ with no repeated roots in $a$:

$$
\frac{b(s)}{a(s)} = \frac{r_1}{s - p_1} + \frac{r_2}{s - p_2} + \cdots + \frac{r_n}{s - p_n} + k(s)
$$

Here $p_i$ are the **poles** (the [roots](/courses/computational-mathematics/polynomials-and-roots#roots) of $a$), $r_i$ are the **residues**, and $k(s)$ holds any direct terms. $k$ is empty when $b$ has a lower degree than $a$.

## An example

Take this transfer function:

$$
\frac{-4s + 8}{s^2 + 6s + 8}
$$

The denominator factors as $(s + 4)(s + 2)$. To find the residue at a pole, cover up that pole's factor and substitute the pole into everything left over:

<CoverUpVisualizer />

MATLAB's `residue` returns the same numbers:

```matlab
b = [-4 8];
a = [1 6 8];
[r, p, k] = residue(b, a)

r =
   -12
     8
p =
    -4
    -2
k =
     []
```

So the fraction equals $\dfrac{-12}{s + 4} + \dfrac{8}{s + 2}$.

## Going back

Give `residue` three inputs, and it converts back to polynomial form:

```matlab
[b2, a2] = residue(r, p, k)

b2 =
    -4     8
a2 =
     1     6     8
```

## In Python

NumPy has no `residue`, but SciPy does (`scipy.signal.residue`). For distinct poles, the rule is short enough to write yourself: a residue is $b(p) / a'(p)$, where $a'$ is the [derivative](/courses/computational-mathematics/derivatives-and-curve-fitting#derivatives) of $a$. That's the cover-up method in one line.

```python
import numpy as np

b = [-4, 8]
a = [1, 6, 8]

p = np.roots(a)
r = np.polyval(b, p) / np.polyval(np.polyder(a), p)

print(np.round(p, 6).tolist())  # [-4.0, -2.0]
print(np.round(r, 6).tolist())  # [-12.0, 8.0]
```

## In machine learning

The link here is less direct than in most lessons, and it comes through filters. An exponential moving average updates as $y_t = \alpha x_t + (1 - \alpha) y_{t-1}$, which is a filter with a single pole. Splitting a complicated filter into fractions breaks it into simple pieces of this kind.

These averages are used a lot in training. Momentum and the Adam optimizer keep moving averages of the gradient, and many models keep one of their own weights to use for evaluation. pandas has them built in:

```python
import pandas as pd

s = pd.Series([1.0, 2.0, 3.0])

print(s.ewm(alpha=0.5, adjust=False).mean().tolist())  # [1.0, 1.5, 2.25]
```
