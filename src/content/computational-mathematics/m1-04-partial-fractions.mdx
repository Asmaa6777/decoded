# Partial Fractions

A ratio of two polynomials can be hard to work with. Split it into a sum of simple fractions and each piece becomes easy to integrate, to invert, or to read off a system's behaviour.

## The expansion

For polynomials $b$ and $a$ with no repeated roots in $a$:

$$
\frac{b(s)}{a(s)} = \frac{r_1}{s - p_1} + \frac{r_2}{s - p_2} + \cdots + \frac{r_n}{s - p_n} + k(s)
$$

Here $p_i$ are the **poles** (the [roots](/courses/computational-mathematics/polynomials-and-roots#roots) of $a$), $r_i$ are the **residues**, and $k(s)$ holds any direct terms. $k$ is empty when $b$ has a lower degree than $a$.

Each piece $\dfrac{r}{s - p}$ is the simplest system there is: something that remembers its past and lets it fade at a fixed rate. Machine learning is full of these. An **exponential moving average** updates as

$$
y_t = \alpha x_t + (1 - \alpha)\, y_{t-1}
$$

so every new value is blended with the running average, and older values fade by a factor of $1 - \alpha$ each step. That's a filter with a single pole. **Momentum** and the **Adam** optimizer, which train most neural networks today, keep moving averages like this of the gradient, so one noisy step can't throw training off course. Many models also keep an averaged copy of their own weights to use at the end, because it's steadier than the last step.

<CodeTabs>

```matlab
x = [1 2 3];
alpha = 0.5;

% filter(b, a, x) runs y(t) = alpha*x(t) + (1 - alpha)*y(t-1).
% The last argument starts the average at the first value.
y = filter(alpha, [1 -(1 - alpha)], x, (1 - alpha) * x(1))

y =
    1.0000    1.5000    2.2500
```

```python
import pandas as pd

s = pd.Series([1.0, 2.0, 3.0])

# adjust=False gives exactly the update above, starting from the first value
print(s.ewm(alpha=0.5, adjust=False).mean().tolist())  # [1.0, 1.5, 2.25]
```

</CodeTabs>

Splitting a complicated filter into partial fractions breaks it into pieces of exactly this kind, each with its own pole and its own rate of fading.

## An example

Take this transfer function:

$$
\frac{-4s + 8}{s^2 + 6s + 8}
$$

The denominator factors as $(s + 4)(s + 2)$. To find the residue at a pole, cover up that pole's factor and substitute the pole into everything left over:

<CoverUpVisualizer />

MATLAB's `residue` returns the same numbers:

<CodeTabs>

```matlab
b = [-4 8];
a = [1 6 8];
[r, p, k] = residue(b, a)

r =
   -12
     8
p =
    -4
    -2
k =
     []
```

```python
import numpy as np

b = [-4, 8]
a = [1, 6, 8]

# For distinct poles the rule fits in one line: the residue at p is b(p) / a'(p),
# where a' is the derivative of a. That's the cover-up method.
p = np.roots(a)
r = np.polyval(b, p) / np.polyval(np.polyder(a), p)

print(np.round(p, 6).tolist())  # [-4.0, -2.0]
print(np.round(r, 6).tolist())  # [-12.0, 8.0]

# SciPy has the full version, which also handles repeated poles.
# It lists the poles in a different order:
from scipy.signal import residue

r2, p2, k2 = residue(b, a)
print(np.round(r2, 6).tolist(), np.round(p2, 6).tolist())  # [8.0, -12.0] [-2.0, -4.0]
```

</CodeTabs>

So the fraction equals $\dfrac{-12}{s + 4} + \dfrac{8}{s + 2}$. In the residue formula, $a'$ is the [derivative](/courses/computational-mathematics/derivatives-and-curve-fitting#derivatives) of $a$.

## Going back

Give `residue` three inputs, and it converts back to polynomial form:

<CodeTabs>

```matlab
[b2, a2] = residue(r, p, k)

b2 =
    -4     8
a2 =
     1     6     8
```

```python
import numpy as np
from scipy.signal import invres

b2, a2 = invres([-12, 8], [-4, -2], [])
print(np.round(b2, 6).tolist(), np.round(a2, 6).tolist())  # [-4.0, 8.0] [1.0, 6.0, 8.0]
```

</CodeTabs>

## Where you'll meet this

<ApplicationsGrid>
<PracticalApplication title="Predicting a system's response" tool="Control theory, Simulink">
Each term $r/(s - p)$ corresponds to an exponential $re^{pt}$ over time. So once you've split a transfer function, you can read how the system responds term by term.
</PracticalApplication>
<PracticalApplication title="Designing filters" tool="Signal processing">
Digital filters are often split into smaller first and second order sections, using this same expansion in its discrete form, which keeps them numerically stable.
</PracticalApplication>
