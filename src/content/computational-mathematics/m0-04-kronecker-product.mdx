# The Kronecker Product

The ordinary matrix product needs sizes that fit together. The **Kronecker product** works with any two matrices and always grows the result, so it's the standard way to build a big structured matrix out of small ones.

## The definition

If $A$ is $m$-by-$n$ and $B$ is $p$-by-$q$, then $A \otimes B$ is $mp$-by-$nq$. Each entry of $A$ scales one whole copy of $B$:

$$
A \otimes B =
\begin{bmatrix}
a_{11}B & a_{12}B & \cdots & a_{1n}B \\
a_{21}B & a_{22}B & \cdots & a_{2n}B \\
\vdots & \vdots & & \vdots \\
a_{m1}B & a_{m2}B & \cdots & a_{mn}B
\end{bmatrix}
$$

## Order changes the pattern

`kron(X, Y)` and `kron(Y, X)` have the same size and the same entries in a different arrangement. Using the [identity matrix](/courses/computational-mathematics/multiplying-matrices#the-identity-matrix) makes this easy to see. With $X = \begin{bmatrix}1 & 2\\3 & 4\end{bmatrix}$ and `I = eye(2)`:

```matlab
kron(X, I)             kron(I, X)

  1  0  2  0             1  2  0  0
  0  1  0  2             3  4  0  0
  3  0  4  0             0  0  1  2
  0  3  0  4             0  0  3  4
```

`kron(I, X)` repeats $X$ down the diagonal. `kron(X, I)` spreads the entries of $X$ apart. Matrices made of zeros and ones are the usual way to stamp out repeated copies like this.

## In Python

```python
import numpy as np

A = np.array([[1, -2], [-1, 0]])
B = np.array([[4, -3], [2, 3]])

print(np.kron(A, B)[0].tolist())  # [4, -3, -8, 6]
print(np.kron(np.eye(2, dtype=int), np.array([[1, 2], [3, 4]]))[2].tolist())  # [0, 0, 1, 2]
```

Plain Python spells out all four loops:

```python
A = [[1, 2]]
B = [[0, 5], [6, 7]]

K = [[a * b for a in ra for b in rb] for ra in A for rb in B]
print(K)  # [[0, 5, 0, 10], [6, 7, 12, 14]]
```

## In machine learning

Some optimizers need the curvature of the loss, a matrix far too large to store or invert. K-FAC approximates each layer's block of it as a Kronecker product of two small matrices. That helps because $(A \otimes B)^{-1} = A^{-1} \otimes B^{-1}$, so [inverting](/courses/computational-mathematics/determinants-and-inverses#the-inverse) two small matrices replaces inverting a huge one.

Gaussian processes on grid-shaped data use the same shortcut, since their covariance matrix often factors this way.
