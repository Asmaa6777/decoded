# Divisibility and the Euclidean Algorithm

Every secure connection your browser opens rests on arithmetic with whole numbers. This module builds that arithmetic from the ground up, starting with what it means for one number to divide another.

## Divisibility

A nonzero integer $b$ **divides** $a$ if $a = m \cdot b$ for some integer $m$, which means division leaves no remainder. We write $b \mid a$ and call $b$ a **divisor** of $a$. The positive divisors of 24 are 1, 2, 3, 4, 6, 8, 12 and 24.

<CodeTabs>

```matlab
n = 100;
find(mod(n, 1:n) == 0)    % every d from 1 to n that leaves no remainder
% divisors(100) gives the same, with the Symbolic Math Toolbox

ans =
     1     2     4     5    10    20    25    50   100
```

```python
n = 100
print([d for d in range(1, n + 1) if n % d == 0])  # [1, 2, 4, 5, 10, 20, 25, 50, 100]
```

</CodeTabs>

Divisibility decides real design choices in AI. A **vision transformer**, the kind of model behind many image recognisers, cuts each picture into square patches and reads them like words in a sentence. The patch size has to divide the image size exactly, or the last row and column of patches would hang off the edge. The standard 224-pixel image with 16-pixel patches works, because $16 \mid 224$: it gives $14 \times 14 = 196$ patches.

## The division algorithm

Divide any integer $a$ by a positive integer $n$ and you get one quotient and one remainder:

$$
a = q \cdot n + r, \qquad 0 \le r < n, \qquad q = \left\lfloor \frac{a}{n} \right\rfloor
$$

Here $\lfloor x \rfloor$ means the largest integer not greater than $x$. The remainder is never negative, and that matters for negative numbers:

- $11 = 1 \cdot 7 + 4$, so $r = 4$
- $-11 = (-2) \cdot 7 + 3$, so $r = 3$

<CodeTabs>

```matlab
q = floor(-11 / 7)    % -2
r = mod(-11, 7)       % 3
```

```python
# divmod returns the quotient and the remainder together
print(divmod(-11, 7))  # (-2, 3)
```

</CodeTabs>

Every training loop does this division. A model learns from small **batches** of examples at a time, so splitting 1000 examples into batches of 32 gives a quotient and a remainder: 31 full batches, and a short final batch of 8. That leftover batch is why PyTorch has a `drop_last` option to throw it away, since an unusually small batch makes for a noisy training step.

<CodeTabs>

```matlab
full_batches = floor(1000 / 32)   % 31
leftover = mod(1000, 32)          % 8
```

```python
print(divmod(1000, 32))  # (31, 8)
```

</CodeTabs>

## Greatest common divisor

$\gcd(a, b)$ is the largest integer dividing both $a$ and $b$. For example, $\gcd(60, 24) = 12$. Signs don't matter, so $\gcd(60, -24) = 12$ too, and by convention $\gcd(0, 0) = 0$.

Two numbers are **coprime** (or relatively prime) when their gcd is 1. Neither has to be prime: $\gcd(8, 15) = 1$.

## The Euclidean algorithm

Listing divisors becomes hopeless for large numbers. Euclid's method needs one fact, which is that $\gcd(a, b) = \gcd(b, a \bmod b)$. Here $a \bmod b$ is the remainder $r$ from the division algorithm above, and the [next lesson](/courses/computational-mathematics/modular-arithmetic#the-mod-operation) is all about it. Keep replacing the pair until the remainder hits zero, and the last non-zero remainder is the answer.

It has a nice picture. Cut as many squares of side $b$ as you can from an $a$-by-$b$ rectangle. Then repeat on the leftover piece. The final square tiles everything before it, and its side is the gcd:

<EuclidTilesVisualizer />

Written out for $\gcd(1281, 243)$:

$$
\begin{aligned}
1281 &= 5 \cdot 243 + 66 \\
243 &= 3 \cdot 66 + 45 \\
66 &= 1 \cdot 45 + 21 \\
45 &= 2 \cdot 21 + 3 \\
21 &= 7 \cdot 3 + 0
\end{aligned}
$$

So $\gcd(1281, 243) = 3$. MATLAB's `gcd` does this for you, and it also works entry by entry on vectors:

<CodeTabs>

```matlab
gcd(65, 70)                                % 5
gcd([250 1050 6022], [180 1150 5622])      % 10  50  2
```

```python
import math
import numpy as np

print(math.gcd(65, 70))  # 5
print(np.gcd([250, 1050, 6022], [180, 1150, 5622]).tolist())  # [10, 50, 2]

# The whole algorithm fits in three lines of plain Python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

print(gcd(1281, 243))  # 3
```

</CodeTabs>
