# Matrix Norms and the Trace

How big is a matrix? Counting its rows doesn't answer that. A 3-by-3 matrix of tiny values and a 3-by-3 matrix of huge values have the same shape. A **norm** turns a matrix into one number, never negative, that measures how large its entries are.

## What every norm promises

There are several norms, but all the ones here share these properties, for any [scalar](/courses/computational-mathematics/matrices-and-matlab#multiplying-by-a-scalar) $k$:

1. $\|A\| \ge 0$: a size is never negative.
2. $\|A\| = 0$ only when $A$ is the zero matrix (all entries 0): anything else has some size.
3. $\|kA\| = |k|\,\|A\|$: doubling every entry doubles the size. Flipping every sign changes nothing, so the rule uses $|k|$ and not $k$.
4. $\|A + B\| \le \|A\| + \|B\|$, the **triangle inequality**. It's named after triangles, where one side is never longer than the other two put together. Adding two matrices can cancel entries, so the total can come out smaller, but never larger.
5. $\|AB\| \le \|A\|\,\|B\|$: the size of a product is at most the two sizes multiplied. This one is true for the three norms below. It isn't true for every way of measuring size, so it's listed on its own.

The symbol $\|A\|$, with double bars, is read "the norm of $A$". It's different from $|A|$ with single bars, which some books use for the [determinant](/courses/computational-mathematics/determinants-and-inverses#what-the-determinant-measures).

## Three norms to know

The **1-norm** is the largest absolute column sum:

$$
\|A\|_1 = \max_{j} \sum_{i=1}^{n} |a_{ij}|
$$

The **infinity-norm** is the largest absolute row sum:

$$
\|A\|_\infty = \max_{i} \sum_{j=1}^{n} |a_{ij}|
$$

A handy way to remember them: "1" is tall and thin like a column, and "∞" is short and wide like a row.

The **Euclidean norm** is the square root of the sum of every entry squared. It's Pythagoras applied to the whole matrix:

$$
\|A\|_E = \sqrt{\sum_{i=1}^{n} \sum_{j=1}^{n} a_{ij}^2}
$$

Here are all three on a small matrix, worked by hand:

$$
A = \begin{bmatrix} 1 & -7 \\ -2 & -3 \end{bmatrix}
$$

- **1-norm.** The absolute column sums are $1 + 2 = 3$ and $7 + 3 = 10$, so $\|A\|_1 = 10$.
- **Infinity-norm.** The absolute row sums are $1 + 7 = 8$ and $2 + 3 = 5$, so $\|A\|_\infty = 8$.
- **Euclidean norm.** $\|A\|_E = \sqrt{1^2 + (-7)^2 + (-2)^2 + (-3)^2} = \sqrt{1 + 49 + 4 + 9} = \sqrt{63} \approx 7.937$.

Take the absolute value before adding. Adding the column $(-7, -3)$ as it stands gives $-10$, and a norm is never negative.

The formulas here are written for a square $n$-by-$n$ matrix, but all three work the same way on a rectangular one, and MATLAB's `norm` accepts either.

The tool below uses one matrix for all three, and they give different answers. There's no single true size, so you choose the norm that fits the problem:

```python
import numpy as np

B = np.array([[5, -4, 2], [-1, 2, 3], [-2, 1, 0]])

print(np.linalg.norm(B, 1))  # 8.0

print(np.linalg.norm(B, "fro"))  # 8.0

# The defaults differ: with no second argument, np.linalg.norm(B) is the
# Euclidean (Frobenius) norm, while MATLAB's norm(B) is the 2-norm.

# In pandas each definition reads as a sum and a max:
import pandas as pd

df = pd.DataFrame(B)
print(df.abs().sum(axis=0).max())  # 8
print(df.abs().sum(axis=1).max())  # 11
```

<details>
<summary>Show the answers</summary>

- $\|P\|_1$: the column sums are $2 + 3 = 5$ and $8 + 1 = 9$, so the answer is **9**.
- $\|Q\|_\infty$: the row sums are $3 + 6 + 1 = 10$, $3 + 1 + 0 = 4$ and $2 + 4 + 7 = 13$, so the answer is **13**.
- $\|R\|_E$: the squares add up to $1 + 49 + 9 + 16 + 4 + 4 + 4 + 1 + 1 = 89$, so the answer is $\sqrt{89} \approx$ **9.434**.

</details>

<Callout tone="orange" label="Watch the name in MATLAB">
Many books call the Euclidean norm the Frobenius norm, and so does MATLAB: use `norm(A, 'fro')`. Plain `norm(A)` computes something else, the 2-norm. It's the most that $A$ can stretch any vector: the vector's length after multiplying by $A$, divided by its length before. Books call it the largest **singular value** of $A$. This course doesn't need it, but it's what you get if you forget the `'fro'`.
</Callout>

Machine learning uses norms to keep a model under control while it trains:

- **Regularization.** A model with huge weights tends to memorise its training data instead of learning the pattern. **Weight decay** adds the squared Euclidean norm of the weights to the loss, so large weights make the loss worse. **Lasso** adds the sum of absolute values instead, which tends to push unhelpful weights to exactly zero. Note that this "L1 penalty" sums all the entries, so it isn't the matrix 1-norm above.
- **Gradient clipping.** Sometimes a gradient comes out enormous, and one step that size would destroy the weights learned so far. So if the gradient's norm goes over a limit, the gradient is scaled down to that length. Its direction stays the same. Large language models are trained with this turned on.

<CodeTabs>

```matlab
g = [30 40];
limit = 5;

clipped = g * min(1, limit / norm(g))

clipped =
     3     4
```

```python
import numpy as np

g = np.array([30.0, 40.0])
limit = 5.0

clipped = g * min(1.0, limit / np.linalg.norm(g))
print(clipped.tolist())  # [3.0, 4.0]
```

</CodeTabs>

## The trace

The **trace** of a square matrix is the sum of its main diagonal:

$$
\begin{aligned} \operatorname{tr}(A) &= \sum_{i=1}^{n} a_{ii} \\ &= a_{11} + a_{22} + \cdots + a_{nn} \end{aligned}
$$

Only square matrices have a trace, because only they have a full diagonal from the top-left corner to the bottom-right. For the small matrix above, $\operatorname{tr}(A) = 1 + (-3) = -2$. Unlike a norm, the trace can be negative. For `magic(4)`, `trace` returns $16 + 11 + 6 + 1 = 34$, which is also what every row and column of that matrix adds up to.

<CodeTabs>

```matlab
trace(magic(4))

ans =
    34
```

```python
import numpy as np

M = np.array([[16, 2, 3, 13], [5, 11, 10, 8], [9, 7, 6, 12], [4, 14, 15, 1]])
print(np.trace(M))  # 34
```

</CodeTabs>

The trace is used in data science too. The **variance** of a feature is the average squared distance of its values from their mean. A feature whose values are spread far apart has a large variance. A covariance matrix has one row and one column per feature. Its diagonal holds the variance of each feature, so its trace is the **total variance** of the data. PCA splits that total into parts and reports how much of it each of its components explains. That's how you decide how many dimensions you can safely remove.
