# Affine Ciphers

A shift cipher only adds. If we multiply as well, we get a larger key space, and the lesson on [modular inverses](/courses/computational-mathematics/modular-inverses) suddenly matters: multiplying only works as a cipher when you can undo it.

## The cipher

An **affine transformation** uses a pair of keys, $k_1$ and $k_2$:

$$
E_{(k_1, k_2)}(m) = k_1 m + k_2 \pmod{26}
$$

If that shape looks familiar, it should. Every layer of a neural network computes $wx + b$, a multiplication followed by a shift, and "affine" is the name for exactly that in both fields. It's why a layer's $b$ is called the **bias**: without it, the layer can only scale, so a layer with no bias is linear but not affine.

To decrypt, subtract $k_2$ and then multiply by the inverse of $k_1$:

$$
D_{(k_1, k_2)}(c) = k_1^{-1}(c - k_2) \pmod{26}
$$

The inverse only exists when $\gcd(k_1, 26) = 1$ ([here's why](/courses/computational-mathematics/modular-inverses#when-an-inverse-exists)), and this is a hard requirement. Drag $k_1$ and watch the lines. When $k_1$ shares a factor with 26, they bunch up on fewer letters, and that information is gone for good:

<CodeTabs>

```matlab
numel(unique(mod(13 * (0:25) + 5, 26)))   % 2: a bad k1 squeezes 26 letters onto 2
numel(unique(mod(7 * (0:25) + 5, 26)))    % 26: a good one keeps them all apart
```

```python
import numpy as np

print(len(set((13 * np.arange(26) + 5) % 26)))  # 2
print(len(set((7 * np.arange(26) + 5) % 26)))  # 26
```

</CodeTabs>

This collapse is the same thing as a [singular matrix](/courses/computational-mathematics/determinants-and-inverses#the-inverse): both send different inputs to the same output, so the information is lost and nothing can undo it. Most neural network layers are happy to throw information away. **Normalizing flows** can't, because they generate images or sounds by running their layers backwards, so they're built only from layers that are guaranteed to be invertible, the network version of insisting that $\gcd(k_1, 26) = 1$.

## Worked example: encrypting

Encrypt SECURITY with $k_1 = 7$ and $k_2 = 21$:

| Letter | $m$ | $7m + 21$ | mod 26 | Result |
| --- | --- | --- | --- | --- |
| S | 18 | 147 | 17 | R |
| E | 4 | 49 | 23 | X |
| C | 2 | 35 | 9 | J |
| U | 20 | 161 | 5 | F |
| R | 17 | 140 | 10 | K |
| I | 8 | 77 | 25 | Z |
| T | 19 | 154 | 24 | Y |
| Y | 24 | 189 | 7 | H |

So SECURITY becomes RXJFKZYH.

<CodeTabs>

```matlab
m = double('SECURITY') - 65;              % letters to numbers, A = 0
char(mod(7 * m + 21, 26) + 65)            % RXJFKZYH
```

```python
import numpy as np

m = np.array([ord(ch) - 65 for ch in "SECURITY"])  # letters to numbers, A = 0
# NumPy applies the formula to the whole message at once
print("".join(chr(n + 65) for n in (7 * m + 21) % 26))  # RXJFKZYH
```

</CodeTabs>

## Worked example: decrypting

To decrypt VLXIJH, first find the inverse of 7 modulo 26 with the [extended Euclidean algorithm](/courses/computational-mathematics/modular-inverses#the-extended-euclidean-algorithm). It's 15, since $7 \cdot 15 = 105 = 4 \cdot 26 + 1$:

| Letter | $c$ | $15(c - 21)$ | mod 26 | Result |
| --- | --- | --- | --- | --- |
| V | 21 | 0 | 0 | A |
| L | 11 | -150 | 6 | G |
| X | 23 | 30 | 4 | E |
| I | 8 | -195 | 13 | N |
| J | 9 | -180 | 2 | C |
| H | 7 | -210 | 24 | Y |

The message is AGENCY.

<CodeTabs>

```matlab
c = double('VLXIJH') - 65;
[~, k1inv] = gcd(7, 26);                  % 15, or -11, which is the same mod 26
char(mod(k1inv * (c - 21), 26) + 65)      % AGENCY
```

```python
c = [ord(ch) - 65 for ch in "VLXIJH"]
k1inv = pow(7, -1, 26)  # 15
print("".join(chr(k1inv * (n - 21) % 26 + 65) for n in c))  # AGENCY
```

</CodeTabs>

## How strong is it?

There are 12 valid values for $k_1$, because [Euler's totient](/courses/computational-mathematics/primality-and-the-totient#eulers-totient-function) gives $\phi(26) = 12$, and 26 for $k_2$. That makes $12 \times 26 = 312$ keys, which a computer tries instantly. It also maps each letter to one fixed letter, so letter frequencies still give it away.

Use $k_1 = 11$ and $k_2 = 23$ to encrypt THE NATIONAL SECURITY AGENCY. The inverse of 11 modulo 26 is 19, so you can check your answer by decrypting with $19(c - 23)$.
</Callout>
