# Kleene's Theorem

You've now met three ways to define a language: regular expressions, finite automata and transition graphs. Transition graphs looked more powerful than finite automata, since they allow word labels, several starts and free moves. Stephen Kleene proved in the 1950s that the extra freedom adds nothing:

> **Kleene's theorem.** Any language that can be defined by a regular expression, a finite automaton or a transition graph can be defined by all three.

The languages they define are the **regular languages**. The proof is a cycle of three conversions. If you can always get from each model to the next, and the last one leads back to the first, the three must describe exactly the same languages.

$$
\text{FA} \;\Rightarrow\; \text{TG} \;\Rightarrow\; \text{RE} \;\Rightarrow\; \text{FA}
$$

1. **FA to TG** is free. Every finite automaton already is a transition graph.
2. **TG to RE** is state elimination, from the last lesson.
3. **RE to FA** is the part left to prove, and it's the one exams ask you to carry out.

## Building an FA from a regular expression

A regular expression is built from letters and $\Lambda$ using union, concatenation and star (see The Language of Languages). So it's enough to show two things: there are FAs for the smallest pieces, and if you have FAs for $r_1$ and $r_2$, you can build FAs for $r_1 + r_2$, $r_1 r_2$ and $r_1^*$. Then any expression can be built up piece by piece, following the way it was written.

The smallest pieces are easy. Here is an FA for the single letter $a$: it accepts $a$ and sends everything else to a dead state.

## The three rules

Each rule builds the new machine as a table of new states $z_1, z_2, \ldots$, where every $z$ stands for a combination of old states. You start from the combination for the start, fill in where each letter leads, and give a name to every combination you haven't seen before. You stop when every row is filled.

**Union, $r_1 + r_2$.** Run both machines side by side. Each new state is a pair, "$x_i$ or $y_j$": FA1 is in $x_i$ and FA2 is in $y_j$. On a letter, both halves move. A pair is final if **either** half is final.

**Concatenation, $r_1 r_2$.** The word has to finish a run of FA1 and then start a run of FA2, but the machine can't know where the split is. So each new state holds FA1's state plus a *set* of FA2 states that are running in parallel. Whenever FA1 reaches a final state, FA2's start joins the set, because a split could happen there. A new state is final if its set contains a final state of FA2.

**Star, $r_1^*$.** The word is several runs of FA1 back to back. Each new state is a set of FA1 states. Whenever a move lands on a final state of FA1, FA1's start joins the set, because a new repetition could begin there. A set containing a final state of FA1 is final.

Try all three on $r_1 = (a + b)^*a$ (words ending in $a$) and $r_2 = ((a + b)(a + b))^*$ (words of even length). Step through the table for each, then run words on the finished machine below it.

For the union, $z_1$ = "$x_1$ or $y_1$" is final already, because $y_1$ is: the empty word has even length. The table ends with four states, one for each combination of "last letter was $a$?" and "length so far is even?".

<Callout tone="orange" label="Why star needs a new start state">
  $r_1^*$ always contains $\Lambda$, so the start must be final. The tempting shortcut is to mark FA1's own start state as final. Try it on $r_1 = (a + b)^*a$: in FA1, the word $b$ leads from $x_1$ back to $x_1$, so the shortcut would accept $b$. But $b$ is not in $r_1^*$, since every repetition of $r_1$ ends in $a$. The construction avoids this by making a **new** start state $z_1$ that is final and that nothing ever returns to.
</Callout>

<Callout tone="violet" label="You've seen the concatenation trick before">
  Tracking a set of FA2 states at once is the subset construction from the NFA lesson. Concatenation and star are naturally nondeterministic (where does one piece end?), and sets of states are how a deterministic machine keeps every possibility open.
</Callout>

## What else follows

The union rule works with any combining condition. Mark a pair final when **both** halves are final, and you get an FA for the **intersection** of two regular languages. Swap final and non-final states in one complete DFA, and you get its **complement**. So regular languages are closed under union, concatenation, star, intersection and complement: none of these operations can take you outside the regular languages.
