# The Language Layer

The second layer is how you tell software what you want: search, the file system, and now prompts. Most people search the way they speak. With AI search that costs less than it used to, but it still leads to vague queries. Learning to structure a query, pick precise keywords and think about how information is indexed changes how quickly you find answers.

## The file system

The file system is part of this language. Folders, paths and directories are how the machine organizes what it holds. Once you understand them, you stop depending on clicking around to find things.

That understanding leads to the terminal, which then stops being a scary interface and becomes a direct line to the system. Instead of clicking through layers, you say where you want to go and what you want to do, and the system responds immediately. Many commands do things the GUI can't do at all. This will help a lot later, when you learn to code and build software.

<Callout tone="violet" label="Build the skill">
Practice using the command line to navigate and manipulate files and directories. Download files from the internet with tools like curl and wget, and get comfortable with package managers like npm and with simple scrapers.
</Callout>

## Prompt literacy

Using AI tools is another form of language, and as with any language, clarity matters. It's tempting to let the system do all the thinking and generate your prompts or ideas for you, but that has a cost: if you stop drafting your own thoughts, you stop developing them.

<Callout tone="violet" label="The amplification rule">
Think first. Write something imperfect. Then use the tool to refine it. That way the machine amplifies your thinking and you keep doing the thinking yourself.
</Callout>
