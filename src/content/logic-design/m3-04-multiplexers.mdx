# Multiplexers and Demultiplexers

In digital systems like microprocessors and communication networks, many functional units share resources such as buses, arithmetic pipelines, and registers. To prevent bus contention and short circuits, systems use switching elements that select a data source from several candidates or route a data stream to one of several destinations.

Two data-steering components perform this routing: the **multiplexer** (data selector) and the **demultiplexer** (data distributor).

## The Multiplexer (Data Selector)

A **multiplexer** (commonly abbreviated as **MUX** or data selector) is a combinational circuit that selects binary data from one of $2^n$ input data lines and directs it to a single output line.

The selection of which input line is connected to the output is controlled by a set of $n$ **select lines** (also called address lines or control lines).

### 2-to-1 multiplexer

The basic multiplexer has two data inputs ($I_0, I_1$), one select line ($S$), and one output ($Y$):

| Select ($S$) | Output ($Y$) | Operational Meaning |
|:---:|:---:|:---|
| 0 | $I_0$ | Input $I_0$ is routed to output $Y$ |
| 1 | $I_1$ | Input $I_1$ is routed to output $Y$ |

The Boolean equation expresses this selection algebraically:
$$
Y = S' I_0 + S I_1
$$

When $S = 0$, the first AND gate is enabled ($S' = 1$), passing $I_0$, while the second AND gate is disabled ($S = 0$), forcing its output to 0. The OR gate passes $I_0 + 0 = I_0$. When $S = 1$, the reverse occurs.

<MuxCircuit />

### CMOS transmission gate multiplexer

In standard-cell CMOS VLSI design, a 2-to-1 MUX is rarely constructed using discrete AND-OR logic. Instead, it is synthesized from two [CMOS transmission gates (TGs)](/courses/logic-design/logic-gates#electrical-parameters-and-real-hardware-constraints) and a single inverter:
- Each transmission gate consists of an nMOS and pMOS transistor wired in parallel.
- When $S = 0$, $TG_0$ is turned ON, creating a low-resistance bilateral switch passing $I_0$ directly to $Y$, while $TG_1$ is OFF.
- When $S = 1$, $TG_1$ turns ON, passing $I_1$, while $TG_0$ turns OFF.

This transmission gate design uses 6 transistors total (4 switch transistors plus 2 inverter transistors), compared to 14 transistors for an AND-OR-INVERT gate implementation. That reduces chip area, static power, and propagation delay.

### 4-to-1 multiplexer

A 4-to-1 multiplexer has four data lines ($I_0, I_1, I_2, I_3$), two select lines ($S_1, S_0$), and an active-LOW **Enable** line ($\overline{E}$):

| $\overline{E}$ | $S_1$ | $S_0$ | Output ($Y$) | Selected Input |
|:---:|:---:|:---:|:---:|:---:|
| 1 | X | X | 0 | None (Disabled) |
| 0 | 0 | 0 | $I_0$ | Channel 0 |
| 0 | 0 | 1 | $I_1$ | Channel 1 |
| 0 | 1 | 0 | $I_2$ | Channel 2 |
| 0 | 1 | 1 | $I_3$ | Channel 3 |

The Boolean logic equation is:
$$
Y = \overline{E}' \cdot \big(S_1' S_0' I_0 + S_1' S_0 I_1 + S_1 S_0' I_2 + S_1 S_0 I_3\big)
$$

The circuit consists of four 3-input AND gates, one 4-input OR gate, and two inverters. Notice that the select logic acts identically to a [2-to-4 decoder](/courses/logic-design/comparators-decoders-encoders#decoders-pick-exactly-one): each AND gate decodes one unique minterm of $(S_1, S_0)$ to enable exactly one data line.

### Commercial MSI multiplexers

Standard 7400-series TTL and CMOS families package multiplexers in diverse configurations:
- **74LS151:** 8-to-1 multiplexer with active-LOW enable ($\overline{E}$) and complementary outputs ($Y$ and $W = Y'$).
- **74LS153:** Dual 4-to-1 multiplexer sharing common select inputs ($S_1, S_0$) with independent enable inputs for each 4-bit section.
- **74LS157:** Quad 2-to-1 multiplexer with common select line and common enable, used to steer whole 4-bit nibbles between registers and buses.

## Implementing Arbitrary Boolean Functions with Multiplexers

A multiplexer can serve as a **universal function generator**. Any combinational logic function can be synthesized directly using a multiplexer without needing external AND, OR, or XOR gates.

### Method 1: Direct implementation with $n$ select lines ($2^n$-to-1 MUX)

For an arbitrary Boolean function of $n$ variables:
1. Connect the $n$ Boolean variables directly to the $n$ select lines $S_{n-1}, \dots, S_0$.
2. The $2^n$ data inputs ($I_0, \dots, I_{2^n-1}$) correspond one-to-one with the $2^n$ [minterms](/courses/logic-design/sop-and-pos#canonical-representations-minterms-and-maxterms) of the truth table.
3. If minterm $m_k$ produces a 1 in the function's truth table, tie data input $I_k$ to logic HIGH ($V_{CC}$).
4. If minterm $m_k$ produces a 0, tie data input $I_k$ to logic LOW (GND).

While simple, this method is hardware-inefficient because a 4-variable function requires a 16-to-1 multiplexer.

### Method 2: Shannon's expansion technique ($n-1$ select lines)

We can cut the multiplexer size in half by applying **Shannon's expansion theorem**: an $n$-variable Boolean function can be implemented using a multiplexer with only $n-1$ select lines (a $2^{n-1}$-to-1 MUX).

Shannon's expansion theorem states that any function $F(X_1, X_2, \dots, X_n)$ can be decomposed around any chosen variable $X_n$:
$$
F(X_1, X_2, \dots, X_n) = X_n' \cdot F(X_1, \dots, 0) + X_n \cdot F(X_1, \dots, 1)
$$

#### Implementation procedure:
1. From the $n$ input variables, choose $n-1$ variables to connect to the select lines (for example, connect $A$ and $B$ to $S_1, S_0$).
2. The remaining variable (e.g. $C$) serves as the data input signal. For each data input $I_k$, the value can only take one of four possible states:
   - $0$ (constant logic 0)
   - $1$ (constant logic 1)
   - $C$ (the variable in true form)
   - $C'$ (the variable inverted)
3. Construct an **implementation table** by listing the minterm pairs that share the same select code:

| Data Input | Select Code ($S_1 S_0$) | Row $C = 0$ | Row $C = 1$ | Derived Input Value |
|:---:|:---:|:---:|:---:|:---:|
| $I_0$ | $00$ | $m_0$ | $m_1$ | Compare outputs for $m_0$ and $m_1$ |
| $I_1$ | $01$ | $m_2$ | $m_3$ | Compare outputs for $m_2$ and $m_3$ |
| $I_2$ | $10$ | $m_4$ | $m_5$ | Compare outputs for $m_4$ and $m_5$ |
| $I_3$ | $11$ | $m_6$ | $m_7$ | Compare outputs for $m_6$ and $m_7$ |

- If neither minterm is circled (both output 0) $\implies I_k = 0$.
- If both minterms are circled (both output 1) $\implies I_k = 1$.
- If only the bottom row ($C=1$) is circled $\implies I_k = C$.
- If only the top row ($C=0$) is circled $\implies I_k = C'$.

### Worked example: 3-variable function on a 4-to-1 MUX

Implement $F(A, B, C) = \sum m(1, 3, 5, 6)$ using a 4-to-1 multiplexer:
1. Connect $A \to S_1$ and $B \to S_0$.
2. Analyze the input pairs with variable $C$:
   - For $S_1 S_0 = 00$: contains minterms $m_0$ and $m_1$. $m_0 = 0$, $m_1 = 1$. Since $F = 1$ only when $C = 1$, set $I_0 = C$.
   - For $S_1 S_0 = 01$: contains minterms $m_2$ and $m_3$. $m_2 = 0$, $m_3 = 1$. Set $I_1 = C$.
   - For $S_1 S_0 = 10$: contains minterms $m_4$ and $m_5$. $m_4 = 0$, $m_5 = 1$. Set $I_2 = C$.
   - For $S_1 S_0 = 11$: contains minterms $m_6$ and $m_7$. $m_6 = 1$, $m_7 = 0$. Since $F = 1$ only when $C = 0$, set $I_3 = C'$.

A single 4-to-1 MUX and one inverter (to produce $C'$) implements the entire 3-variable logic function.

## Multiplexer Expansion (Tree Networks)

When an application requires selecting from more inputs than a single IC provides, smaller multiplexers can be cascaded into a hierarchical **multiplexer tree**.

### Synthesizing a 16-to-1 MUX using 4-to-1 MUXes

To choose from 16 inputs ($I_0\dots I_{15}$) with 4 select lines ($S_3, S_2, S_1, S_0$), five 4-to-1 multiplexers can be arranged in a two-tier tree with zero external gates:

```
Inputs I0 - I3   ───►┌─────────┐
                     │ 4:1 MUX │───► D0
S1, S0 ───────────┬─►└─────────┘
                  │
Inputs I4 - I7   ─┼─►┌─────────┐
                  │  │ 4:1 MUX │───► D1
                  ├─►└─────────┘     ┌─────────┐
                  │                  │ 4:1 MUX │───► Final Output Y
Inputs I8 - I11  ─┼─►┌─────────┐     │         │
                  │  │ 4:1 MUX │───► D2│         │
                  ├─►└─────────┘  ┌─►└─────────┘
                  │               │   ▲
Inputs I12 - I15 ─┼─►┌─────────┐  │   │
                  │  │ 4:1 MUX │──┼─► D3
                  └─►└─────────┘  │
                                  │
S3, S2 ───────────────────────────┴─────────────
```

- **First Tier (4 MUXes):** The four lower multiplexers receive data inputs $I_0\dots I_{15}$. Their select lines are wired in parallel to the two least significant address bits ($S_1, S_0$).
- **Second Tier (1 MUX):** The fifth multiplexer receives the four intermediate outputs ($D_0, D_1, D_2, D_3$) as its data inputs. Its select lines are connected to the two most significant address bits ($S_3, S_2$).

When $S_3 S_2 S_1 S_0 = 1011_2$:
1. $S_1 S_0 = 11_2$ causes each first-tier MUX to output its fourth input ($I_3, I_7, I_{11}, I_{15}$).
2. $S_3 S_2 = 10_2$ causes the second-tier MUX to route input $D_2$ (which carries $I_{11}$) to the final output $Y$.

## Demultiplexers (Data Distributors)

A **demultiplexer** (commonly abbreviated as **DEMUX**) performs the exact inverse operation of a multiplexer: it takes a single input data line ($D$) and routes it to one of $2^n$ output lines determined by $n$ select lines. All unselected output lines remain inactive (logic 0 for active-HIGH circuits, or logic 1 for active-LOW circuits).

<DemuxCircuit />

### Equivalence to decoders with enable

A demultiplexer is structurally and functionally identical to a [decoder with an enable input](/courses/logic-design/comparators-decoders-encoders#2-to-4-line-decoder-with-enable):
- In a decoder, the enable input turns the outputs on or off while the address inputs select which output is asserted.
- If we treat the decoder's **Enable pin as the Data input ($D$)**, and treat the decoder's address pins as the Select lines, the decoder becomes a demultiplexer!

For a 1-to-4 demultiplexer with data input $D$ and select lines $S_1, S_0$:
$$
Y_0 = D \cdot S_1' S_0', \quad Y_1 = D \cdot S_1' S_0, \quad Y_2 = D \cdot S_1 S_0', \quad Y_3 = D \cdot S_1 S_0
$$

When $D = 0$, all outputs are forced to 0 regardless of $S_1, S_0$. When $D = 1$, the selected output line follows $D$ to logic 1 while all other lines remain 0. These equations are algebraically identical to a 2-to-4 decoder with an active-HIGH enable input $E = D$. Commercial decoder ICs, such as the 74LS138, are labeled in manufacturer datasheets as **"3-to-8 Line Decoder / Demultiplexer"**.

## Applications in Processor Datapaths and Buses

Multiplexers and demultiplexers route data throughout microprocessors:

1. **ALU Operand Routing:**
   In an instruction like `ADD R1, R2, R3`, the processor's register file contains many general-purpose registers. Dual multiplexer trees select which two register outputs are delivered to inputs $A$ and $B$ of the ALU. The register fields within the [instruction format](/courses/computer-architecture/instruction-formats) drive the multiplexer select lines directly.

2. **Bidirectional Bus Sharing:**
   Computers connect dozens of memory modules and peripheral chips across a common system [bus](/courses/computer-organization/buses). Multiplexers gate which subsystem drives data onto the bus during any given clock cycle, preventing bus contention.

3. **Time-Division Multiplexing (TDM):**
   In telecommunications, multiple digitized voice or data channels take turns transmitting across a single high-speed physical wire or optical fiber. A multiplexer at the transmitter samples each channel in round-robin sequence, while a demultiplexer at the receiver reconstitutes the original individual streams.

4. **Parallel-to-Serial Conversion:**
   Systems converting parallel byte registers for [serial transmission](/courses/logic-design/signals#serial-transmission) (such as UART interfaces) use an 8-to-1 multiplexer whose data inputs are loaded with an 8-bit byte. A modulo-8 binary counter cycles through select inputs $S_2 S_1 S_0$, causing the byte to stream out serially bit by bit over a single pin.

## Common exam pitfalls and student mistakes

When working with multiplexers and demultiplexers, students often make these six mistakes:

1. **Reversing Select Line Weights:** Connecting the MSB of the control variable to $S_0$ and the LSB to $S_1$. For example, an input condition $AB = 10_2$ ($2_{10}$) will assert select pattern $S_1 S_0 = 01_2$ ($1_{10}$), causing the multiplexer to output channel $I_1$ instead of $I_2$. Select line indices must strictly mirror binary place values ($S_k$ has weight $2^k$).
2. **Inverting Residues in Shannon's Implementation Tables:** Confusing the data assignment rule when decomposing a function. In the implementation table, if only the minterm in row $C = 0$ is 1, the data input is $C'$, NOT $C$. If only the minterm in row $C = 1$ is 1, the data input is $C$. If both rows are 1, the input is constant 1; if neither row is 1, the input is constant 0.
3. **Leaving Active-LOW Enable Pins ($\overline{E}$) Floating or Tied HIGH:** Overlooking that standard commercial multiplexers (like the 74LS151 or 74LS153) use an active-LOW strobe/enable line. Tying $\overline{E}$ to $V_{CC}$ (or leaving it floating in CMOS circuits) permanently disables the chip, forcing all data outputs to 0 regardless of the select inputs.
4. **Multiplexer Expansion Tier Reversal:** Wiring the high-order select lines ($S_3, S_2$) to the first tier of multiplexers instead of the final selector tier. The first tier must partition the contiguous lower bits ($S_1, S_0$) so that each first-tier multiplexer handles a contiguous 4-element block ($I_0\dots I_3$, $I_4\dots I_7$, etc.), while the second tier uses the higher-order bits to select between blocks.
5. **Ignoring Timing Glitches during Multi-Bit Select Transitions:** Assuming multiplexer switching is hazard-free. If two inputs are both logic 1 ($I_1 = 1$ and $I_2 = 1$), transitioning between them ($S_1 S_0 = 01 \to 10$) requires two bits to change state simultaneously. If bit $S_0$ falls slightly before $S_1$ rises, the select inputs momentarily pass through intermediate state $00$. If input $I_0 = 0$, the multiplexer output produces a momentary downward glitch to 0.
6. **Confusing Multiplexers with Encoders or Decoders:** Multiplexers select between multiple *data streams* onto a single line based on an address; decoders convert an *address* into a 1-hot wire; priority encoders convert multiple active status wires into an *address*.

### Problem 5: Multi-level multiplexer synthesis with residue functions

Synthesize the 4-variable Boolean function:
$$F(A, B, C, D) = \sum m(0, 1, 3, 4, 8, 9, 15)$$
using a single 4-to-1 multiplexer and the minimum number of standard external 2-input logic gates.
1. Assign $A$ and $B$ to multiplexer select inputs $S_1$ and $S_0$ respectively ($S_1 = A, S_0 = B$).
2. Use Shannon's expansion theorem to find the four residue functions $F_{00}(C, D), F_{01}(C, D), F_{10}(C, D),$ and $F_{11}(C, D)$ that feed data inputs $I_0, I_1, I_2, I_3$.
3. Minimize each residue function algebraically or with 2-variable Karnaugh maps, and specify the external gates needed to drive the multiplexer data lines.

<ModelAnswer>
1. **Shannon Decomposition around $A$ and $B$:**
   The function expands as:
   $$F(A, B, C, D) = A'B' \cdot I_0 + A'B \cdot I_1 + AB' \cdot I_2 + AB \cdot I_3$$
   We partition the 16 minterms by their $(A, B)$ prefix:
   - For $AB = 00$ (minterms $m_0$ to $m_3$):
     - Minterms present: $m_0$ ($0000_2$), $m_1$ ($0001_2$), $m_3$ ($0011_2$).
     - Residue truth values for $(C, D) \in \{00, 01, 10, 11\}$:
       - $(0, 0) \to m_0 = 1$
       - $(0, 1) \to m_1 = 1$
       - $(1, 0) \to m_2 = 0$
       - $(1, 1) \to m_3 = 1$
     - K-map for $I_0(C, D)$: 1-cells at $(0,0), (0,1), (1,1)$. Only cell $(1,0)$ is 0.
     - Group $(0,0)$ and $(0,1)$ to get $C'$. Group $(0,1)$ and $(1,1)$ to get $D$.
     - Minimal SOP for $I_0$:
       $$I_0 = C' + D$$

   - For $AB = 01$ (minterms $m_4$ to $m_7$):
     - Minterms present: $m_4$ ($0100_2$). Minterms $m_5, m_6, m_7$ are absent.
     - Residue truth values for $(C, D)$:
       - $(0, 0) \to m_4 = 1$
       - $(0, 1) \to m_5 = 0$
       - $(1, 0) \to m_6 = 0$
       - $(1, 1) \to m_7 = 0$
     - Minimal expression for $I_1$:
       $$I_1 = C' D' = (C + D)' \quad (\text{a 2-input NOR gate})$$

   - For $AB = 10$ (minterms $m_8$ to $m_{11}$):
     - Minterms present: $m_8$ ($1000_2$), $m_9$ ($1001_2$). Minterms $m_{10}, m_{11}$ are absent.
     - Residue truth values for $(C, D)$:
       - $(0, 0) \to m_8 = 1$
       - $(0, 1) \to m_9 = 1$
       - $(1, 0) \to m_{10} = 0$
       - $(1, 1) \to m_{11} = 0$
     - Notice that whenever $C = 0$, $F = 1$, regardless of $D$. When $C = 1$, $F = 0$.
     - Minimal expression for $I_2$:
       $$I_2 = C'$$

   - For $AB = 11$ (minterms $m_{12}$ to $m_{15}$):
     - Minterms present: $m_{15}$ ($1111_2$). Minterms $m_{12}, m_{13}, m_{14}$ are absent.
     - Residue truth values for $(C, D)$:
       - $(0, 0) \to m_{12} = 0$
       - $(0, 1) \to m_{13} = 0$
       - $(1, 0) \to m_{14} = 0$
       - $(1, 1) \to m_{15} = 1$
     - Minimal expression for $I_3$:
       $$I_3 = CD \quad (\text{a 2-input AND gate})$$

2. **Hardware Implementation Summary:**
   - One 4-to-1 multiplexer (select lines $S_1 = A, S_0 = B$).
   - One inverter to generate $C'$.
   - One 2-input OR gate computing $I_0 = C' + D$.
   - One 2-input NOR gate computing $I_1 = (C + D)' = C' D'$.
   - Direct connection from inverter output to $I_2 = C'$.
   - One 2-input AND gate computing $I_3 = CD$.
   Total gates: 1 MUX, 1 inverter, 1 OR, 1 NOR, 1 AND.

<Callout tone="orange" label="Common exam pitfall">
Students frequently map the minterm numbers into the wrong residue channels. Remember that for $AB = 01$, the binary indices have an offset of $0100_2 = 4$. Minterm 4 has relative coordinates $(C,D) = (0,0)$, minterm 5 has $(0,1)$, and so on. Swapping the select variable order ($S_1=B, S_0=A$) scrambles all four residue equations.
</Callout>
</ModelAnswer>

### Problem 6: Transmission Gate CMOS multiplexers and single-cycle Barrel Shifters

Modern digital datapaths (such as ARM and RISC-V execution pipelines) use transmission gate (TG) multiplexers and barrel shifters to execute arbitrary bit shifts in a single clock cycle.
1. A CMOS transmission gate consists of an nMOS and pMOS transistor connected in parallel, controlled by complementary select signals ($S$ and $S'$). Explain why a single NMOS pass transistor is insufficient to pass a logic 1, and why a single PMOS pass transistor cannot pass a logic 0.
2. Draw the schematic topology of a 2-to-1 multiplexer using two transmission gates ($TG_0$ and $TG_1$) and one inverter. State the total transistor count and compare it to a static CMOS NAND-NAND multiplexer.
3. Design a 4-bit barrel shifter capable of circular rotating a 4-bit word $D = D_3 D_2 D_1 D_0$ to the right by $k \in \{0, 1, 2, 3\}$ positions using two stages of 2-to-1 multiplexers controlled by select bits $S_1$ and $S_0$ (where $k = 2S_1 + S_0$).

<ModelAnswer>
1. **Need for Complementary Transmission Gates:**
   - **NMOS pass transistor:** Passes a strong logic 0 (pulls cleanly to ground $0\text{V}$). However, when passing a logic 1 ($V_{DD}$), the source voltage rises until $V_{GS} = V_{DD} - V_{\text{out}} = V_{tn}$ (the threshold voltage). The transistor turns OFF prematurely, passing only a degraded "weak 1" ($V_{DD} - V_{tn}$).
   - **PMOS pass transistor:** Passes a strong logic 1 (pulls cleanly to $V_{DD}$). However, when passing a logic 0 ($0\text{V}$), $V_{SG} = V_{\text{out}} - 0 = |V_{tp}|$. The transistor cuts off, passing only a degraded "weak 0" ($|V_{tp}|$).
   - **Transmission Gate (TG):** By wiring NMOS and PMOS in parallel with opposite gate polarities ($S$ on NMOS, $S'$ on PMOS), the NMOS pulls the node down cleanly to $0\text{V}$ and the PMOS pulls it up cleanly to $V_{DD}$. The result is a bidirectional, full rail-to-rail analog switch.

2. **2-to-1 Transmission Gate Multiplexer Architecture:**
   - **Circuit Topology:**
     - $TG_0$ connects input $I_0$ to output $Y$. Its NMOS gate connects to $S'$ and PMOS gate connects to $S$.
     - $TG_1$ connects input $I_1$ to output $Y$. Its NMOS gate connects to $S$ and PMOS gate connects to $S'$.
     - An inverter produces $S'$ from $S$.
     - When $S = 0$: $TG_0$ is ON, passing $I_0 \to Y$. $TG_1$ is OFF.
     - When $S = 1$: $TG_1$ is ON, passing $I_1 \to Y$. $TG_0$ is OFF.
   - **Transistor Count Comparison:**
     - Each transmission gate uses 2 transistors ($1\text{ NMOS} + 1\text{ PMOS}$).
     - The inverter uses 2 transistors ($1\text{ NMOS} + 1\text{ PMOS}$).
     - Total TG MUX transistor count: $2 \times 2 + 2 = 6\text{ transistors}$.
     - Static CMOS NAND-NAND MUX: requires two 2-input NAND gates ($2 \times 4 = 8$), one 2-input NAND output stage ($4$), and an inverter on $S$ ($2$), totaling **14 transistors**.
     - The transmission gate MUX uses **57% fewer transistors** and provides faster propagation delay without static shoot-through current.

3. **4-Bit Barrel Shifter Design (Rotate Right by $k$):**
   A barrel shifter performs multi-bit shifting in $O(1)$ clock cycles using $\log_2(4) = 2$ multiplexer stages:
   - **Stage 1 (Controlled by $S_0$, shifts by 1 position if $S_0 = 1$):**
     Consists of four 2-to-1 MUXes producing intermediate vector $W = W_3 W_2 W_1 W_0$:
     - For $S_0 = 0$: $W$ passes $D$ unchanged ($W_i = D_i$).
     - For $S_0 = 1$: $W$ rotates $D$ right by 1 bit:
       $$W_3 = (S_0=0 ? D_3 : D_0)$$
       $$W_2 = (S_0=0 ? D_2 : D_3)$$
       $$W_1 = (S_0=0 ? D_1 : D_2)$$
       $$W_0 = (S_0=0 ? D_0 : D_1)$$

   - **Stage 2 (Controlled by $S_1$, shifts by 2 positions if $S_1 = 1$):**
     Consists of four 2-to-1 MUXes taking intermediate vector $W$ and producing final output $Y = Y_3 Y_2 Y_1 Y_0$:
     - For $S_1 = 0$: $Y$ passes $W$ unchanged ($Y_i = W_i$).
     - For $S_1 = 1$: $Y$ rotates $W$ right by 2 bits:
       $$Y_3 = (S_1=0 ? W_3 : W_1)$$
       $$Y_2 = (S_1=0 ? W_2 : W_0)$$
       $$Y_1 = (S_1=0 ? W_1 : W_3)$$
       $$Y_0 = (S_1=0 ? W_0 : W_2)$$

   - **Operation Trace:**
     - If $k = 0$ ($S_1 S_0 = 00$): Stage 1 shift = 0, Stage 2 shift = 0 $\implies$ total rotate = 0.
     - If $k = 1$ ($S_1 S_0 = 01$): Stage 1 shift = 1, Stage 2 shift = 0 $\implies$ total rotate = 1.
     - If $k = 2$ ($S_1 S_0 = 10$): Stage 1 shift = 0, Stage 2 shift = 2 $\implies$ total rotate = 2.
     - If $k = 3$ ($S_1 S_0 = 11$): Stage 1 shift = 1, Stage 2 shift = 2 $\implies$ total rotate = $1 + 2 = 3$.
   Every possible rotation from 0 to 3 positions stabilizes within the propagation delay of just two 2-to-1 multiplexers.

<Callout tone="orange" label="Common exam pitfall">
Students often attempt to build barrel shifters by cascading serial shift registers and clocking them multiple times. A shift register requires $k$ clock cycles (variable latency), whereas a barrel shifter is purely combinational logic that completes the shift in a fraction of a single clock cycle.
</Callout>
</ModelAnswer>
