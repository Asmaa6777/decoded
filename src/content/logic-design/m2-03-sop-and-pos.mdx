# Truth Tables to Circuits: SOP and POS

When designing a digital circuit, the engineer begins with a functional specification, such as "trigger the fire alarm if temperature exceeds threshold and smoke is detected, or if the manual pull station is activated." This specification is captured in a **truth table**, listing every input combination and its required binary output.

To turn a truth table into physical gates, switching theory provides two standard representations:
1. **Sum of Products (SOP):** A two-level circuit of AND gates feeding an OR gate.
2. **Product of Sums (POS):** A two-level circuit of OR gates feeding an AND gate.

Three terms define the building blocks:
- A **literal** is a variable in uncomplemented form ($A$) or complemented form ($A'$). An $n$-variable circuit has $2n$ possible literals.
- A **product term** is one or more literals combined with logical AND (such as $A B' C$).
- A **sum term** is one or more literals combined with logical OR (such as $A + B' + C$).

## Canonical representations: Minterms and Maxterms

A Boolean expression is **canonical** when every product or sum term contains all $n$ input variables of the system, each appearing exactly once.

### Minterms ($m_i$) and the Sum of Minterms

A **minterm** (or standard product) of $n$ variables is a product term that contains each of the $n$ variables in either true or complemented form. Why call it a *minterm*? It evaluates to logic 1 for the **minimum possible non-empty domain**, exactly one input row out of all $2^n$ combinations in the truth table. For all other $2^n - 1$ rows, it evaluates to 0.

For $n$ variables, there are exactly $2^n$ distinct minterms, denoted $m_0, m_1, \dots, m_{2^n - 1}$.

**Binary index rule for minterms:**
- Assign bit **1** to uncomplemented variables ($A = 1$).
- Assign bit **0** to complemented variables ($A' = 0$).

For three variables $(A, B, C)$:
- Row $0$ ($000_2$): $m_0 = A'B'C'$
- Row $1$ ($001_2$): $m_1 = A'B'C$
- Row $5$ ($101_2$): $m_5 = AB'C$
- Row $7$ ($111_2$): $m_7 = ABC$

Any Boolean function $F$ can be written as the OR combination of all minterms where the output is 1. This is the **Canonical Sum of Minterms** (or Disjunctive Normal Form), expressed in compact summation notation:
$$
F(A, B, C) = \sum m(1, 3, 5, 7) = m_1 + m_3 + m_5 + m_7
$$

### Maxterms ($M_i$) and the Product of Maxterms

A **maxterm** (or standard sum) of $n$ variables is a sum term that contains each of the $n$ variables in either true or complemented form. Why call it a *maxterm*? It evaluates to logic 1 for the **maximum possible proper domain**, $2^n - 1$ rows out of all $2^n$ combinations. It evaluates to logic 0 on strictly one input combination.

There are $2^n$ distinct maxterms, denoted $M_0, M_1, \dots, M_{2^n - 1}$.

**Binary index rule for maxterms:**
- Assign bit **0** to uncomplemented variables ($A = 0$).
- Assign bit **1** to complemented variables ($A' = 1$).

<Callout tone="neon" label="Watch the index inversion">
Students frequently invert the maxterm rule. In minterms, 1 is uncomplemented ($A$). In maxterms, **0 is uncomplemented ($A$) and 1 is complemented ($A'$)**. 

Row $5$ ($101_2$) yields:
- Minterm: $m_5 = A B' C$ (evaluates to 1 when $A=1, B=0, C=1$)
- Maxterm: $M_5 = A' + B + C'$ (evaluates to 0 when $A=1, B=0, C=1$)
</Callout>

Each maxterm $M_i$ evaluates to logic **0** for exactly one input row (row $i$) and evaluates to **1** for all other rows.

Any Boolean function $F$ can be written as the AND combination of all maxterms where the output is 0. This is the **Canonical Product of Maxterms** (or Conjunctive Normal Form), expressed in compact product notation:
$$
F(A, B, C) = \prod M(0, 2, 4, 6) = M_0 \cdot M_2 \cdot M_4 \cdot M_6
$$

### Relationship between Minterms and Maxterms

By De Morgan's theorem, each maxterm is the algebraic complement of its corresponding minterm:
$$
m_i' = M_i \qquad\text{and}\qquad M_i' = m_i
$$

For example, on row 5:
$$
m_5' = (AB'C)' = A' + B'' + C' = A' + B + C' = M_5
$$

Because every truth table row produces either 0 or 1, the minterms of a function and its maxterms form disjoint partitions of the index set $\{0, 1, \dots, 2^n - 1\}$:
$$
F = \sum m(\text{list of 1-rows}) = \prod M(\text{list of 0-rows})
$$

The complement of the function ($F'$) is obtained by interchanging the 1-rows and 0-rows:
$$
F' = \sum m(\text{list of 0-rows}) = \prod M(\text{list of 1-rows})
$$

## Standard SOP and POS vs. Canonical Forms

While canonical expressions are unique and easy to derive from a truth table, they are large because every term includes every variable. 

In **standard SOP** and **standard POS** forms, terms can have fewer literals:
- **Standard SOP:** $F = AB + C'D + AC$ (Two-level AND-OR structure)
- **Standard POS:** $F = (A + B)(C' + D)(A + C)$ (Two-level OR-AND structure)

Standard forms reduce the number of gate inputs and transistors on the chip while keeping two-level propagation delay ($2 \cdot t_{pd}$).

## Converting non-canonical expressions to canonical forms

To expand a non-canonical equation into canonical sum-of-minterms or product-of-maxterms:

### Expansion to Canonical SOP
Multiply any incomplete product term by $(x + x') = 1$ for each missing variable $x$, distribute, and eliminate duplicates using $w + w = w$.

**Worked Example:** Express $F(A, B, C) = AB + C'$ in canonical $\sum m$ form.
1. Term $AB$ lacks variable $C$:
   $$
   AB = AB(C + C') = ABC + ABC' = m_7 + m_6
   $$
2. Term $C'$ lacks variables $A$ and $B$:
   $$
   \begin{aligned}
   C' &= (A + A')C' = AC' + A'C' \\
   &= AC'(B + B') + A'C'(B + B') \\
   &= AB C' + AB'C' + A'BC' + A'B'C' \\
   &= m_6 + m_4 + m_2 + m_0
   \end{aligned}
   $$
3. Combine and remove the duplicate $m_6$:
   $$
   F = m_0 + m_2 + m_4 + m_6 + m_7 = \sum m(0, 2, 4, 6, 7)
   $$

### Expansion to Canonical POS
Add $xx' = 0$ for each missing variable $x$, apply the distributive rule $X + YZ = (X + Y)(X + Z)$, and eliminate duplicates.

**Worked Example:** Express $G(A, B, C) = (A + B')(B + C)$ in canonical $\prod M$ form.
1. Term $(A + B')$ lacks variable $C$:
   $$
   A + B' = A + B' + CC' = (A + B' + C)(A + B' + C') = M_2 \cdot M_3
   $$
2. Term $(B + C)$ lacks variable $A$:
   $$
   B + C = AA' + B + C = (A + B + C)(A' + B + C) = M_0 \cdot M_4
   $$
3. Combine:
   $$
   G = M_0 \cdot M_2 \cdot M_3 \cdot M_4 = \prod M(0, 2, 3, 4)
   $$

## Incompletely specified functions: Don't-Care conditions

In practical systems, certain input combinations:
1. **Can never physically occur:** For example, a [BCD decoder](/courses/logic-design/codes-and-floating-point#bcd-decimal-digits-one-at-a-time) receives 4-bit inputs representing decimal digits $0$ to $9$. Binary patterns $1010_2$ through $1111_2$ ($10_{10}$ to $15_{10}$) are forbidden.
2. **Produce irrelevant outputs:** The output state has no impact on system operation.

These conditions are designated **don't-cares**, written as $d$ or $X$:
$$
F(A, B, C, D) = \sum m(1, 3, 7, 11, 15) + \sum d(0, 2, 5)
$$

Because the circuit will never see these inputs during normal operation, the designer can assign each don't-care condition as either 1 or 0, whichever produces the simplest, lowest-cost gate network.

## Hardware implementation metrics: Two-level logic trade-offs

When choosing between SOP and POS implementations, engineers evaluate three hardware metrics:
1. **Literal count:** The total number of literal appearances across the expression. In CMOS design, each literal input corresponds to two transistors in the first logic level.
2. **Gate input count:** The total number of inputs across all gates (first level plus second level). Measures required routing interconnect area.
3. **Propagation delay:** Both SOP (AND-OR) and POS (OR-AND) are two-level networks with an inherent latency of two gate delays ($2 \cdot t_{pd}$), excluding any input inverters.

Why is two-level logic the theoretical speed baseline of digital design? Regardless of whether the function has 3, 5, or 10 variables, every signal path traverses at most two cascaded gate stages: first-level ANDs into an OR, or first-level ORs into an AND. Multi-level circuits (3 or more levels) can sometimes reduce the total number of gates, but they do so by inserting intermediate nodes that increase total propagation delay to $3 \cdot t_{pd}, 4 \cdot t_{pd}$, or more.

If a truth table contains mostly 1s, the 0-rows are fewer, making the Product of Sums (POS) smaller and cheaper. If the table contains mostly 0s, the Sum of Products (SOP) is smaller.

## Common exam pitfalls and student mistakes

When converting truth tables to algebraic circuits, students commonly make these five mistakes:

1. **Minterm vs. Maxterm Index Reversal:** This is the most frequent error on digital logic exams.
   - For **minterms** ($m_i$): $1 = \text{uncomplemented variable } (A)$, and $0 = \text{complemented variable } (A')$. E.g., row $101_2 \implies m_5 = AB'C$.
   - For **maxterms** ($M_i$): $0 = \text{uncomplemented variable } (A)$, and $1 = \text{complemented variable } (A')$. E.g., row $101_2 \implies M_5 = A' + B + C'$.
2. **Confusing the Maxterm Product of $F$ with $F'$:** A function $F$ is expressed in maxterms using its **0-rows**: $F = \prod M(\text{0-rows})$. Students often incorrectly write $F' = \prod M(\text{0-rows})$. Writing $F'$ with the 0-rows would make $F'$ evaluate to 0 on the 0-rows, which reverses the function. The correct complement relationships are:
   $$
   F = \sum m(\text{1-rows}) = \prod M(\text{0-rows})
   $$
   $$
   F' = \sum m(\text{0-rows}) = \prod M(\text{1-rows})
   $$
3. **Illegal Algebraic Operations in POS Expansion:** To expand an incomplete SOP term such as $AB$, you multiply by $(C + C') = 1$, which is straightforward. But to expand an incomplete POS term such as $(A + B')$, you cannot multiply by anything. You must add $0 = CC'$, and then use the second distributive law $X + YZ = (X+Y)(X+Z)$ to obtain $(A + B' + C)(A + B' + C')$. Students often make mistakes here.
4. **Treating Don't-Cares as Mandatory 1s:** A don't-care ($X$) does not have to be covered. It should only be included in a group if doing so doubles the group size (eliminating a variable literal) or merges two separate groups into one. Forcing every don't-care into a group creates unnecessary gates.
5. **Omitting the Output Gate in Gate Input Counts:** When counting gate inputs for hardware area estimation, students often sum only the inputs to the first-level gates ($3 \times 2 = 6$) and forget to add the inputs to the second-level gate ($+3$), resulting in an undercount.

### Problem 1: Majority voter canonical representations

A digital voting circuit has three inputs: $A$, $B$, and $C$. The output $F$ must be 1 if and only if a majority (at least two) of the voters vote YES (1).

1. Construct the truth table.
2. Write $F$ in canonical Sum of Minterms ($\sum m$) notation.
3. Write $F$ in canonical Product of Maxterms ($\prod M$) notation.

<ModelAnswer>
1. **Truth Table:**

| Row | $A$ | $B$ | $C$ | $F$ | Minterm / Maxterm |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | 0 | 0 | $M_0 = A + B + C$ |
| 1 | 0 | 0 | 1 | 0 | $M_1 = A + B + C'$ |
| 2 | 0 | 1 | 0 | 0 | $M_2 = A + B' + C$ |
| 3 | 0 | 1 | 1 | 1 | $m_3 = A'BC$ |
| 4 | 1 | 0 | 0 | 0 | $M_4 = A' + B + C$ |
| 5 | 1 | 0 | 1 | 1 | $m_5 = AB'C$ |
| 6 | 1 | 1 | 0 | 1 | $m_6 = ABC'$ |
| 7 | 1 | 1 | 1 | 1 | $m_7 = ABC$ |

2. **Canonical Sum of Minterms:**
   Rows with output 1 are 3, 5, 6, 7:
   $$
   F(A, B, C) = \sum m(3, 5, 6, 7) = A'BC + AB'C + ABC' + ABC
   $$

3. **Canonical Product of Maxterms:**
   Rows with output 0 are 0, 1, 2, 4:
   $$
   F(A, B, C) = \prod M(0, 1, 2, 4) = (A + B + C)(A + B + C')(A + B' + C)(A' + B + C)
   $$
</ModelAnswer>

### Problem 2: Algebraic expansion to canonical POS

Convert $F(A, B, C) = (A' + B)(B' + C)$ into canonical Product of Maxterms form showing each step.

<ModelAnswer>
1. **Expand first term $(A' + B)$ missing variable $C$:**
   Add $CC' = 0$:
   $$
   A' + B = A' + B + CC' = (A' + B + C)(A' + B + C')
   $$
   Evaluate maxterm indices:
   - For $A' + B + C$: $A=1, B=0, C=0 \implies 100_2 = 4 \implies M_4$
   - For $A' + B + C'$: $A=1, B=0, C=1 \implies 101_2 = 5 \implies M_5$

2. **Expand second term $(B' + C)$ missing variable $A$:**
   Add $AA' = 0$:
   $$
   B' + C = AA' + B' + C = (A + B' + C)(A' + B' + C)
   $$
   Evaluate maxterm indices:
   - For $A + B' + C$: $A=0, B=1, C=0 \implies 010_2 = 2 \implies M_2$
   - For $A' + B' + C$: $A=1, B=1, C=0 \implies 110_2 = 6 \implies M_6$

3. **Form the canonical product:**
   $$
   F(A, B, C) = M_2 \cdot M_4 \cdot M_5 \cdot M_6 = \prod M(2, 4, 5, 6)
   $$
</ModelAnswer>

### Problem 3: Function complementation in canonical forms

Given the 4-variable function:
$$
F(A, B, C, D) = \sum m(0, 2, 5, 7, 8, 10, 12, 13, 15)
$$

1. Express the complement $F'$ in canonical sum of minterms notation.
2. Express the complement $F'$ in canonical product of maxterms notation.

<ModelAnswer>
1. **$F'$ in Canonical Sum of Minterms:**
   The minterms where $F' = 1$ are precisely the minterms where $F = 0$. The complete index set for 4 variables is $\{0, 1, 2, \dots, 15\}$.
   Subtracting the minterm list of $F$:
   $$
   \{0, \dots, 15\} \setminus \{0, 2, 5, 7, 8, 10, 12, 13, 15\} = \{1, 3, 4, 6, 9, 11, 14\}
   $$
   Therefore:
   $$
   F' = \sum m(1, 3, 4, 6, 9, 11, 14)
   $$

2. **$F'$ in Canonical Product of Maxterms:**
   A function's maxterm list contains the indices where that function is 0. Since $F' = 0$ on the exact rows where $F = 1$:
   $$
   F' = \prod M(0, 2, 5, 7, 8, 10, 12, 13, 15)
   $$
</ModelAnswer>

### Problem 4: Hardware implementation comparison

A function is defined as $F(A, B, C) = \sum m(1, 2, 3, 7)$.

1. Find the minimal SOP expression.
2. Find the minimal POS expression.
3. Compare both implementations by counting total gates, literal appearances, and total gate inputs.

<ModelAnswer>
1. **Minimal SOP:**
   The function's minterms are $m_1 (001_2), m_2 (010_2), m_3 (011_2), m_7 (111_2)$.
   Combine adjacent minterm pairs using $xy + xy' = x$:
   - Pair $(m_1, m_3)$: $A'B'C + A'BC = A'C(B' + B) = A'C$
   - Pair $(m_2, m_3)$: $A'BC' + A'BC = A'B(C' + C) = A'B$
   - Pair $(m_3, m_7)$: $A'BC + ABC = BC(A' + A) = BC$

   Verify whether any term can be omitted:
   - Minterm $m_1 (001)$ is covered only by prime implicant $A'C$.
   - Minterm $m_2 (010)$ is covered only by prime implicant $A'B$.
   - Minterm $m_7 (111)$ is covered only by prime implicant $BC$.

   Because each prime implicant covers a distinguished minterm, all three are Essential Prime Implicants. The minimal SOP expression is:
   $$
   F_{\text{SOP}} = A'B + A'C + BC
   $$

2. **Minimal POS:**
   The function's 0-rows correspond to maxterms $M_0 (000_2), M_4 (100_2), M_5 (101_2), M_6 (110_2)$.
   Combine adjacent maxterm pairs using $(X + Y)(X + Y') = X$:
   - Pair $(M_0, M_4)$: $(A + B + C)(A' + B + C) = B + C$
   - Pair $(M_4, M_5)$: $(A' + B + C)(A' + B + C') = A' + B$
   - Pair $(M_4, M_6)$: $(A' + B + C)(A' + B' + C) = A' + C$

   Verify whether any factor can be omitted:
   - Maxterm $M_0 (000)$ is covered only by sum term $(B + C)$.
   - Maxterm $M_5 (101)$ is covered only by sum term $(A' + B)$.
   - Maxterm $M_6 (110)$ is covered only by sum term $(A' + C)$.

   Each sum term is an essential prime implicant of the complement. The minimal POS expression is:
   $$
   F_{\text{POS}} = (B + C)(A' + B)(A' + C)
   $$

3. **Hardware Comparison:**

| Metric | SOP Implementation ($A'B + A'C + BC$) | POS Implementation ($(B+C)(A'+B)(A'+C)$) |
|---|---|---|
| **First-Level Gates** | Three 2-input AND gates | Three 2-input OR gates |
| **Second-Level Gate** | One 3-input OR gate | One 3-input AND gate |
| **Total Gate Count** | 4 gates (plus 1 inverter for $A'$) | 4 gates (plus 1 inverter for $A'$) |
| **Literal Count** | 6 literals ($A', B, A', C, B, C$) | 6 literals ($B, C, A', B, A', C$) |
| **Total Gate Inputs** | $(3 \times 2) + 3 = 9$ inputs | $(3 \times 2) + 3 = 9$ inputs |
| **Propagation Delay** | $2 \cdot t_{pd}$ (excluding inverter) | $2 \cdot t_{pd}$ (excluding inverter) |

Both two-level architectures are completely symmetric in silicon cost and timing performance for this function.
</ModelAnswer>
