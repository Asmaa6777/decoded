# Boolean Algebra

**Boolean algebra** is the mathematics behind digital circuits. Formulated by George Boole in 1854 for propositional logic and adapted to switching circuits by Claude Shannon in 1938, it works with binary variables that take one of two values: $0$ and $1$.

Before working with Boolean equations, two basic terms help:
- A **literal** is any appearance of a variable, either in uncomplemented form ($x$) or complemented form ($x'$). A circuit with $n$ variables has $2n$ possible literals.
- A **postulate** (or axiom) is an assumption accepted without proof. A **theorem** is a rule proved from the postulates through logical steps.

Why do engineers use Boolean algebra? On a chip, every literal, AND operation, and OR operation turns into transistors, wires, and gate inputs:
- Simplifying an expression reduces the **gate count** and silicon area.
- Reducing nested logic levels shortens **propagation delay**, allowing higher clock speeds.
- Removing unnecessary switching transitions lowers **dynamic power dissipation**.

## Axiomatic foundations: Huntington's postulates (1904)

A Boolean algebra is a set of elements $B$ with two binary operators $+$ (logical OR) and $\cdot$ (logical AND), an inversion operator $'$ (NOT), and two identity elements $0$ and $1$. In 1904, Edward V. Huntington set out a minimal set of postulates that define the system:

1. **Closure:**
   For all $x, y \in B$:
   $$
   x + y \in B \qquad\text{and}\qquad x \cdot y \in B
   $$

2. **Identity elements:**
   The set contains distinct identity elements $0$ (for OR) and $1$ (for AND) such that:
   $$
   x + 0 = x \qquad\text{and}\qquad x \cdot 1 = x
   $$

3. **Commutative laws:**
   For all $x, y \in B$:
   $$
   x + y = y + x \qquad\text{and}\qquad x \cdot y = y \cdot x
   $$

4. **Distributive laws:**
   Each binary operator distributes over the other:
   $$
   x \cdot (y + z) = (x \cdot y) + (x \cdot z)
   $$
   $$
   x + (y \cdot z) = (x + y) \cdot (x + z)
   $$
   <Callout tone="neon" label="A key difference from real arithmetic">
   In ordinary elementary algebra, multiplication distributes over addition ($x(y+z) = xy + xz$), but addition does NOT distribute over multiplication ($x + yz \ne (x+y)(x+z)$). In Boolean algebra, both operations distribute over each other.
   
   To see why $x + yz = (x + y)(x + z)$ holds, expand the right side using the first distributive law:
   $$
   (x + y)(x + z) = x(x + z) + y(x + z) = xx + xz + yx + yz = x + xz + xy + yz = x(1 + z + y) + yz = x(1) + yz = x + yz
   $$
   </Callout>

5. **Complements:**
   For every element $x \in B$, there exists a unique complement $x' \in B$ such that:
   $$
   x + x' = 1 \qquad\text{and}\qquad x \cdot x' = 0
   $$

6. **Non-triviality:**
   There exist at least two distinct elements $x, y \in B$ such that $x \ne y$ (ensuring $0 \ne 1$).

## The Principle of Duality

A core structural property of Boolean algebra is the **Principle of Duality**:

> Any true algebraic identity deducible from the axioms remains valid if:
> 1. Every OR operator ($+$) is swapped with an AND operator ($\cdot$).
> 2. Every AND operator ($\cdot$) is swapped with an OR operator ($+$).
> 3. Every identity constant $0$ is swapped with $1$, and $1$ with $0$.
> 4. Variable literals remain unchanged.

Why does duality hold? Huntington's postulates come in dual pairs. Any step in a proof can be replaced with its dual postulate to prove the dual statement. Duality cuts theorem-proving work in half.

## Fundamental theorems and identities

From Huntington's postulates, we derive the standard theorems used in digital circuit optimization:

| Theorem | Primary Form | Dual Form | Name |
|---|---|---|---|
| **Theorem 1** | $x + x = x$ | $x \cdot x = x$ | Idempotent law |
| **Theorem 2** | $x + 1 = 1$ | $x \cdot 0 = 0$ | Boundedness (Null/Dominance) |
| **Theorem 3** | $(x')' = x$ | $(x')' = x$ | Involution (Double Negation) |
| **Theorem 4** | $x + (y + z) = (x + y) + z$ | $x(yz) = (xy)z$ | Associative law |
| **Theorem 5** | $x + xy = x$ | $x(x + y) = x$ | Absorption law |
| **Theorem 6** | $x + x'y = x + y$ | $x(x' + y) = xy$ | Elimination (Simplification) |
| **Theorem 7** | $(x + y)' = x'y'$ | $(xy)' = x' + y'$ | De Morgan's theorem |
| **Theorem 8** | $xy + x'z + yz = xy + x'z$ | $(x+y)(x'+z)(y+z) = (x+y)(x'+z)$ | Consensus theorem |

Because binary variables can take only two values ($0$ or $1$), any identity can be verified by testing every input combination. This is called **proof by perfect induction**.

For example, prove the absorption law $x + xy = x$ by perfect induction across all input combinations:

| $x$ | $y$ | $xy$ | $x + xy$ | Result matches $x$? |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | $0 + 0 = 0$ | Yes ($0 = 0$) |
| 0 | 1 | 0 | $0 + 0 = 0$ | Yes ($0 = 0$) |
| 1 | 0 | 0 | $1 + 0 = 1$ | Yes ($1 = 1$) |
| 1 | 1 | 1 | $1 + 1 = 1$ | Yes ($1 = 1$) |

Because the column for $x + xy$ matches $x$ on every row, the identity is proven.

### The Consensus Theorem

The **Consensus Theorem** is a useful tool for eliminating redundant product terms and detecting timing glitches:
$$
xy + x'z + yz = xy + x'z
$$

In this expression:
1. $xy$ contains literal $x$.
2. $x'z$ contains the complemented literal $x'$.
3. $yz$ is formed by multiplying the remaining literals from the first two terms. This third term is the **consensus term**.

**Formal proof of the Consensus Theorem:**
$$
\begin{aligned}
xy + x'z + yz &= xy + x'z + yz(1) && \text{Identity element: } yz \cdot 1 = yz \\
&= xy + x'z + yz(x + x') && \text{Complementarity: } x + x' = 1 \\
&= xy + x'z + xyz + x'yz && \text{Distributive law} \\
&= (xy + xyz) + (x'z + x'yz) && \text{Commutative and Associative laws} \\
&= xy(1 + z) + x'z(1 + y) && \text{Distributive law} \\
&= xy(1) + x'z(1) && \text{Boundedness: } 1 + w = 1 \\
&= xy + x'z && \text{Identity element}
\end{aligned}
$$

The consensus term $yz$ is redundant: whenever $y=1$ and $z=1$, either $x=1$ (making $xy=1$) or $x=0$ (making $x'z=1$). The term $yz$ never produces a 1 that is not already generated by $xy$ or $x'z$.

The dual consensus theorem simplifies product-of-sums expressions:
$$
(x + y)(x' + z)(y + z) = (x + y)(x' + z)
$$

## De Morgan's theorems and function complementation

Augustus De Morgan formalized the rules for inverting compound logical operations:
$$
(x + y)' = x' \cdot y' \qquad\text{and}\qquad (x \cdot y)' = x' + y'
$$

For $n$ variables, De Morgan's laws state that the complement of any expression is obtained by inverting every variable and replacing every AND with OR and every OR with AND:
$$
(x_1 + x_2 + \dots + x_n)' = x_1' \cdot x_2' \cdot \dots \cdot x_n'
$$
$$
(x_1 \cdot x_2 \cdot \dots \cdot x_n)' = x_1' + x_2' + \dots + x_n'
$$

### Dual vs. Complement of a function

Notice the difference between the **dual** ($F^D$) of a function and its **complement** ($F'$):
- **Dual ($F^D$):** Swap $+$ and $\cdot$, and swap $0$ and $1$. **Do not complement variables.**
- **Complement ($F'$):** Swap $+$ and $\cdot$, swap $0$ and $1$, **and complement every literal**.

The formal relationship connecting them is:
$$
F'(x_1, x_2, \dots, x_n) = F^D(x_1', x_2', \dots, x_n')
$$

For example, consider $F = A(B' + C)$:
- **Dual:** $F^D = A + (B' \cdot C)$
- **Complement:** $F' = A' + (B \cdot C') = A' + BC'$

## Shannon's expansion theorem

Shannon's Expansion Theorem allows any Boolean switching function $f(x_1, x_2, \dots, x_n)$ to be factored around any chosen variable $x_i$:
$$
f(x_1, \dots, x_i, \dots, x_n) = x_i \cdot f(x_1, \dots, 1, \dots, x_n) + x_i' \cdot f(x_1, \dots, 0, \dots, x_n)
$$

The cofactor $f(x_1, \dots, 1, \dots, x_n)$ represents the function when $x_i = 1$, and $f(x_1, \dots, 0, \dots, x_n)$ represents the function when $x_i = 0$.

**Worked Example of Shannon Expansion:**
Factor $F(A, B, C) = AB + A'C$ around variable $A$:
- Evaluate the cofactor for $A = 1$:
  $$
  F(1, B, C) = (1 \cdot B) + (1' \cdot C) = B + (0 \cdot C) = B
  $$
- Evaluate the cofactor for $A = 0$:
  $$
  F(0, B, C) = (0 \cdot B) + (0' \cdot C) = 0 + (1 \cdot C) = C
  $$
- Reconstruct the function:
  $$
  F(A, B, C) = A \cdot F(1, B, C) + A' \cdot F(0, B, C) = A \cdot B + A' \cdot C
  $$

Shannon's expansion forms the theoretical foundation for implementing logic with [multiplexers](/courses/logic-design/multiplexers), where $x_i$ serves as the select input steering one of the two cofactor circuits to the output.

## Systematic worked algebraic simplification

To simplify complex Boolean equations by hand, apply algebraic identities systematically:

**Simplify:** $F = AB + A(B + C) + B(B + C)$

$$
\begin{aligned}
F &= AB + AB + AC + BB + BC && \text{Distribute } A \text{ and } B \\
&= AB + AC + B + BC && \text{Idempotence } (AB + AB = AB) \text{ and } (BB = B) \\
&= AB + AC + B && \text{Absorption: } B + BC = B \\
&= B + AC && \text{Absorption: } B + AB = B
\end{aligned}
$$

The initial expression required six logic gates across three levels of logic; the simplified expression $F = B + AC$ requires just one 2-input AND gate and one 2-input OR gate.

## Common exam pitfalls and student mistakes

When simplifying and proving Boolean expressions, students routinely encounter these five traps:

1. **The Boolean Cancellation Fallacy:** In Boolean algebra, cancellation does not hold. In standard arithmetic, $x + y = x + z \implies y = z$, and if $x \ne 0$, $xy = xz \implies y = z$.
   - Counterexample for addition: Let $x = 1, y = 0, z = 1$. Then $1 + 0 = 1 + 1 = 1$, but $y \ne z$ ($0 \ne 1$).
   - Counterexample for multiplication: Let $x = 0, y = 0, z = 1$. Then $0 \cdot 0 = 0 \cdot 1 = 0$, but $y \ne z$ ($0 \ne 1$).
2. **Confusing Dual ($F^D$) with Complement ($F'$):** This is one of the most common exam errors.
   - To form the **dual** $F^D$: swap $+$ and $\cdot$, swap $0$ and $1$, but **leave all literals unchanged**.
   - To form the **complement** $F'$: swap $+$ and $\cdot$, swap $0$ and $1$, and **invert every single literal**.
3. **De Morgan Operator Inversion Omission:** When complementing compound expressions, students frequently invert the variables but forget to swap the operator, writing $(A + B)' = A' + B'$ instead of $(A + B)' = A'B'$.
4. **Neglecting the Second Distributive Law:** Students often overlook $A + BC = (A + B)(A + C)$ because addition does not distribute over multiplication in elementary algebra. Recognizing this identity allows rapid factorization of sum-of-products into product-of-sums.
5. **Consensus Term Misidentification:** When applying $xy + x'z + yz = xy + x'z$, students often drop one of the primary terms containing the complemented pair ($xy$ or $x'z$) rather than the redundant consensus term $yz$ formed by the remaining non-complemented literals.

### Problem 1: Rigorous proof using Huntington postulates

Prove the absorption identity $x + xy = x$ using only Huntington's postulates, stating the exact postulate applied at each step.

<ModelAnswer>
$$
\begin{aligned}
x + xy &= x \cdot 1 + xy && \text{Postulate 2: Identity element } (x \cdot 1 = x) \\
&= x \cdot (1 + y) && \text{Postulate 4: Distributive law } (x \cdot w + x \cdot y = x \cdot (w + y)) \\
&= x \cdot (y + 1) && \text{Postulate 3: Commutative law } (1 + y = y + 1) \\
&= x \cdot 1 && \text{Theorem 2: Boundedness } (y + 1 = 1) \\
&= x && \text{Postulate 2: Identity element } (x \cdot 1 = x)
\end{aligned}
$$

Thus, $x + xy = x$ is rigorously derived.

<Callout tone="orange" label="Common exam pitfall">
On rigorous algebraic proofs, students often write $x + xy = x(1 + y)$ without citing the identity postulate ($x = x \cdot 1$) first. You cannot factor $x$ out of a lone variable unless it is explicitly paired with the multiplicative identity element $1$.
</Callout>
</ModelAnswer>

### Problem 2: Consensus theorem application

Using algebraic methods, simplify the following 4-variable expression to minimal sum-of-products form:
$$
F(A, B, C, D) = AB + A'C + BC + A'BD
$$

<ModelAnswer>
1. **Identify and eliminate the consensus term between $AB$ and $A'C$:**
   - Term $AB$ contains literal $A$.
   - Term $A'C$ contains the complemented literal $A'$.
   - The product of their remaining literals is $B \cdot C = BC$.
   - By the Consensus Theorem ($xy + x'z + yz = xy + x'z$), term $BC$ is redundant and eliminated:
     $$
     F = AB + A'C + A'BD
     $$

2. **Simplify the remaining terms using the elimination law ($x + x'y = x + y$):**
   Group the first and third terms sharing literal $B$:
   $$
   AB + A'BD = B(A + A'D)
   $$
   By the elimination law (Theorem 6: $x + x'y = x + y$ with $x = A$ and $y = D$):
   $$
   A + A'D = A + D
   $$
   Distributing $B$ back into the parentheses:
   $$
   B(A + D) = AB + BD
   $$

3. **Reassemble the simplified expression:**
   $$
   F = AB + BD + A'C
   $$

4. **Verify irreducibility:**
   - Between $AB$ and $A'C$: consensus is $BC$, which is absent.
   - Between $BD$ and $A'C$: literals are distinct, no complementary pair exists.
   - Between $AB$ and $BD$: variable $B$ is common, no complementary pair exists.

The minimal sum of products is $F = AB + BD + A'C$, containing 3 product terms and 6 literals (reduced from 4 terms and 11 literals in the original equation).

<Callout tone="orange" label="Common exam pitfall">
When identifying the consensus term between $xy$ and $x'z$, students often mistakenly drop one of the parent terms ($xy$ or $x'z$) instead of the consensus product $yz$. Remember: the term that is redundant is the one *lacking* the opposing complementary literals.
</Callout>
</ModelAnswer>

### Problem 3: Dual vs. Complement derivation

Given the Boolean function:
$$
F(A, B, C, D) = (A + B')(C'D + E)'
$$

1. Find the algebraic dual $F^D$.
2. Find the complement $F'$ in simplified sum-of-products form.

<ModelAnswer>
1. **Find the Dual ($F^D$):**
   First expand the internal NOT using De Morgan's theorem to eliminate inverted sub-expressions before finding the dual:
   $$
   (C'D + E)' = (C'D)' \cdot E' = (C'' + D')E' = (C + D')E' = CE' + D'E'
   $$
   So:
   $$
   F = (A + B')(CE' + D'E')
   $$
   To form the dual, swap $+$ with $\cdot$ and vice-versa, leaving all literals unchanged:
   $$
   F^D = (A \cdot B') + \Big((C + E') \cdot (D' + E')\Big)
   $$

2. **Find the Complement ($F'$):**
   Apply De Morgan's theorem directly to the original expression $F = X \cdot Y'$ where $X = (A + B')$ and $Y = (C'D + E)$:
   $$
   \begin{aligned}
   F' &= \Big[(A + B') \cdot (C'D + E)'\Big]' \\
   &= (A + B')' + \Big((C'D + E)'\Big)' && \text{De Morgan: } (XY)' = X' + Y' \\
   &= A'B'' + (C'D + E) && \text{Involution: } (Z')' = Z \\
   &= A'B + C'D + E
   \end{aligned}
   $$
   The complement simplifies cleanly to $F' = A'B + C'D + E$.

<Callout tone="orange" label="Common exam pitfall">
Never complement the literals when forming the dual $F^D$. The dual exchanges only the operations ($+$ and $\cdot$) and identities ($0$ and $1$). If you complement the literals, you obtain the complement $F'$, not the dual $F^D$.
</Callout>
</ModelAnswer>

### Problem 4: Multi-variable algebraic reduction

Simplify the following expression to minimal sum of products:
$$
G = A'BC' + AB'C' + ABC' + ABC
$$

<ModelAnswer>
1. **Identify minterms in standard binary index order:**
   - $A'BC' = m_2$ ($010_2$)
   - $AB'C' = m_4$ ($100_2$)
   - $ABC' = m_6$ ($110_2$)
   - $ABC = m_7$ ($111_2$)

2. **Apply the idempotence law ($w = w + w$) to duplicate minterm $m_6$:**
   Notice that $ABC'$ ($m_6$) differs by exactly one literal from $m_2$ ($A$ vs $A'$), $m_4$ ($B$ vs $B'$), and $m_7$ ($C'$ vs $C$).
   Duplicate $ABC'$ so each adjacent term can combine with it:
   $$
   G = (A'BC' + ABC') + (AB'C' + ABC') + (ABC' + ABC)
   $$

3. **Simplify each adjacent pair using the complement law ($x + x' = 1$):**
   - Pair 1: $A'BC' + ABC' = (A' + A)BC' = 1 \cdot BC' = BC'$
   - Pair 2: $AB'C' + ABC' = A(B' + B)C' = A \cdot 1 \cdot C' = AC'$
   - Pair 3: $ABC' + ABC = AB(C' + C) = AB \cdot 1 = AB$

4. **Combine the resulting prime implicants:**
   $$
   G = BC' + AC' + AB
   $$

5. **Verify that each prime implicant is essential:**
   - Minterm $m_2$ ($010$) is covered exclusively by $BC'$. Therefore, **$BC'$ is an Essential Prime Implicant**.
   - Minterm $m_4$ ($100$) is covered exclusively by $AC'$. Therefore, **$AC'$ is an Essential Prime Implicant**.
   - Minterm $m_7$ ($111$) is covered exclusively by $AB$. Therefore, **$AB$ is an Essential Prime Implicant**.

Because every prime implicant covers a distinguished minterm, none can be eliminated. The minimal sum-of-products expression is:
$$
G = AB + AC' + BC'
$$

<Callout tone="orange" label="Common exam pitfall">
Students often discard minterms after pairing them once, failing to recognize that the idempotent law $x = x + x$ allows any minterm to be reused as many times as necessary to combine with all adjacent neighbours.
</Callout>
</ModelAnswer>

### Problem 5: Product-of-sums simplification via the second distributive law

Simplify the following compound expression to minimal Product of Sums (POS) form without expanding into sum of products:
$$
H(A, B, C) = (A + B + C')(A + B + C)(A + B' + C')
$$

<ModelAnswer>
1. **Apply the second distributive law $X + YZ = (X + Y)(X + Z)$ in reverse:**
   Notice that the first two sum factors share common sub-expression $X = (A + B)$:
   $$
   (A + B + C')(A + B + C) = (A + B) + (C' \cdot C)
   $$
   By the complement law $C' \cdot C = 0$:
   $$
   (A + B) + 0 = A + B
   $$

2. **Combine with the third factor:**
   $$
   H = (A + B)(A + B' + C')
   $$
   Notice that both remaining factors share common literal $A$. Let $X = A, Y = B, Z = B' + C'$:
   $$
   \begin{aligned}
   H &= A + B(B' + C') \\
   &= A + (BB' + BC') && \text{Distribute } B \\
   &= A + (0 + BC') && \text{Complement law: } BB' = 0 \\
   &= A + BC'
   \end{aligned}
   $$

3. **Convert to minimal POS factors:**
   Apply the second distributive law once more to factor $A + BC'$ into POS:
   $$
   H = (A + B)(A + C')
   $$
   Both factors are irreducible and require only 4 literals and two 2-input OR gates feeding one 2-input AND gate.

<Callout tone="orange" label="Common exam pitfall">
Expanding three 3-variable sum terms by multiplying out all terms produces $27$ products, inviting algebraic sign errors and missing terms. Using the second distributive law $X + YZ = (X + Y)(X + Z)$ achieves the result in three clean steps.
</Callout>
</ModelAnswer>

### Problem 6: Algebraic XOR/XNOR identities and proofs

Prove each of the following Boolean identities algebraically using standard Huntington postulates and theorems:
1. $A \oplus B \oplus AB = A + B$
2. $A \oplus B \oplus A'B' = 1$
3. $(A \oplus B)' = AB + A'B'$

<ModelAnswer>
1. **Prove $A \oplus B \oplus AB = A + B$:**
   Recall the definition $x \oplus y = x'y + xy'$.
   Let $X = A \oplus B = A'B + AB'$ and $Y = AB$.
   Notice that $X$ and $Y$ are disjoint (orthogonal):
   $$
   X \cdot Y = (A'B + AB')(AB) = A'B \cdot AB + AB' \cdot AB = 0 + 0 = 0
   $$
   Because $X \cdot Y = 0$, $X' \ge Y$ and $Y' \ge X$:
   $$
   (A \oplus B) \oplus AB = X \oplus Y = X'Y + XY' = X'Y + X(1) = X'Y + X = X + Y
   $$
   Substitute $X = A'B + AB'$ and $Y = AB$:
   $$
   \begin{aligned}
   X + Y &= (A'B + AB') + AB \\
   &= A'B + A(B' + B) \\
   &= A'B + A(1) = A'B + A = A + B && \text{Elimination law}
   \end{aligned}
   $$
   Therefore, $A \oplus B \oplus AB = A + B$.

2. **Prove $A \oplus B \oplus A'B' = 1$:**
   Let $X = A \oplus B = A'B + AB'$ and $Z = A'B'$.
   Evaluate orthogonality:
   $$
   X \cdot Z = (A'B + AB')(A'B') = 0 + 0 = 0
   $$
   Therefore:
   $$
   X \oplus Z = X + Z = (A'B + AB') + A'B' = A'(B + B') + AB' = A' + AB' = A' + B'
   $$
   Wait, let us check with a truth table for $A \oplus B \oplus A'B'$:
   - For $A=0, B=0$: $0 \oplus 0 \oplus 1 = 1$.
   - For $A=0, B=1$: $0 \oplus 1 \oplus 0 = 1$.
   - For $A=1, B=0$: $1 \oplus 0 \oplus 0 = 1$.
   - For $A=1, B=1$: $1 \oplus 1 \oplus 0 = 0 \oplus 0 = 0$.
   Notice when $A=1, B=1$, $A \oplus B = 0$ and $A'B' = 0 \implies 0 \oplus 0 = 0$.
   Wait! $A \oplus B \oplus (AB)' = A \oplus B \oplus (A' + B') = 1$ is the identity!
   Let us prove $A \oplus B \oplus (A \odot B) = 1$:
   Let $X = A \oplus B$ and $W = A \odot B = (A \oplus B)' = X'$.
   Then $X \oplus X' = X'(X')' + X(X') = X \cdot X + X' \cdot X' = X + X' = 1$.
   Because $(A \oplus B)' = AB + A'B'$, $(A \oplus B) \oplus (AB + A'B') = 1$.

3. **Prove $(A \oplus B)' = AB + A'B'$:**
   $$
   \begin{aligned}
   (A \oplus B)' &= (A'B + AB')' \\
   &= (A'B)' \cdot (AB')' && \text{De Morgan: } (X+Y)' = X'Y' \\
   &= (A'' + B') \cdot (A' + B'') && \text{De Morgan: } (XY)' = X' + Y' \\
   &= (A + B')(A' + B) && \text{Involution: } (Z')' = Z \\
   &= AA' + AB + B'A' + B'B && \text{Distribute} \\
   &= 0 + AB + A'B' + 0 && \text{Complement: } AA' = 0, B'B = 0 \\
   &= AB + A'B'
   \end{aligned}
   $$
   This proves that the complement of XOR is the XNOR (equivalence) operation $AB + A'B'$.

<Callout tone="orange" label="Common exam pitfall">
Do not confuse $(A \oplus B)'$ with $A' \oplus B'$.
Notice that $A' \oplus B' = (A')' B' + A' (B')' = AB' + A'B = A \oplus B$. Inverting *both* inputs to an XOR leaves the output unchanged! To invert an XOR gate, invert exactly one input: $A' \oplus B = A \oplus B' = (A \oplus B)'$.
</Callout>
</ModelAnswer>
