# The Memory Unit: Putting It All Together

We have built basic logic gates, assembled them into combinational arithmetic adders and multiplexers, introduced feedback loops to create latches and edge-triggered flip-flops, and chained flip-flops into multi-bit registers and counters.

Now, we combine all of these fundamental components to build the primary memory of a computer: **Random-Access Memory (RAM)**.

Think of computer memory as a massive grid of numbered post-office boxes:
- Each box stores a fixed-length group of bits called a **word**.
- The unique identification number on each box is its **address**.
- An internal combinational [decoder](/courses/logic-design/comparators-decoders-encoders#decoders-pick-exactly-one) converts any binary address into a physical electrical signal that opens one specific box.

| Subsystem | Underlying Circuit | Architectural Function |
|:---|:---|:---|
| **Storage Cells** | Cross-coupled [latches](/courses/logic-design/d-latch-and-clock) or [flip-flops](/courses/logic-design/flip-flops) | Store binary bits in organized rows and columns |
| **Address Bus** | $k$ unidirectional address lines | Specify which memory word is selected |
| **Address Decoder** | Combinational AND gate network | Decodes $k$ address bits to activate exactly one word line ($2^k$) |
| **Read / Write Control** | Steering gates (/CS, /WE, /OE) | Selects whether cells capture data (Write) or drive data (Read) |
| **Data Bus** | $n$ bidirectional wires with [tri-state buffers](#tri-state-logic-and-shared-system-buses) | Transmit the $n$-bit data word into or out of the selected location |

## Memory Capacity and Address Mathematics

The capacity of a memory unit is governed by the number of **address lines** ($k$) and the number of **data bits per word** ($n$):

$$
\text{Capacity} = 2^k \times n \text{ bits} = \frac{1}{8}(2^k \times n) \text{ bytes}
$$

- An address bus of $k$ bits can uniquely address $2^k$ distinct memory words.
- In the interactive simulation above, $k = 3$ address lines access $2^3 = 8$ words of $n = 4$ bits each, yielding a capacity of $8 \times 4 = 32$ bits.
- A memory with 10 address lines and 8-bit words holds $2^{10} \times 8 = 1,024 \text{ bytes}$ ($1\text{ KB}$).
- A 16-bit address bus accesses $2^{16} = 65,536 \text{ words}$ ($64\text{ KB}$).
- The [8086 processor's 20 address lines](/courses/microprocessors/segments-and-addresses) address $2^{20} = 1,048,576 \text{ bytes}$ ($1\text{ MB}$).

### The True Meaning of "Random Access"

In sequential storage media (such as magnetic tapes or shift-register FIFOs), accessing a piece of data requires mechanically or electrically winding past all intervening data. Access time depends entirely on where the data is stored.

In **Random-Access Memory (RAM)**, the word "random" means that **any arbitrary memory location can be accessed in the exact same amount of time**, regardless of its physical address coordinate. This is because address selection is performed by a combinational decoder: the signal propagation delay through the decoder gates is identical for every address line.

## The Internal 1-Bit Binary Storage Cell (BC)

At the intersection of each word row and bit column sits an elementary 1-bit **Binary Cell (BC)**:

```
                      Data In (I)
                           |
                           v
                     +-----------+
                     | Steering  |
      Select ------->|   Gates   |
                     +-----------+
                           |
                           v
                     +-----------+
                     |  D Latch  |
                     +-----------+
                           |
                           v
                     +-----------+
  Read/Write ------->| Tri-State |
                     |  Buffer   |
                     +-----------+
                           |
                           v
                      Data Out (Y)
```

The binary cell contains three primary functions:
1. **Bistable Storage:** A cross-coupled latch or flip-flop that stores the bit.
2. **Select Line ($Sel$):** Driven by the address decoder. When $Sel = 0$, the cell is completely disconnected from internal data buses. When $Sel = 1$, the cell is activated for a read or write operation.
3. **Read/Write Control ($R/W'$):**
   - **Write ($R/W' = 0$):** The input steering gate opens, routing the external data input bit $I$ into the latch.
   - **Read ($R/W' = 1$):** The output tri-state buffer is enabled, driving the stored bit onto the internal output bit line.

## Address Decoding: 1D vs 2D Coincident Decoding

How does a memory unit decode addresses efficiently when scaling to millions of words?

### 1D (Linear) Decoding

In a 1D decoding architecture, a single $k$-to-$2^k$ decoder converts the $k$-bit address directly into $2^k$ word select lines.
- For a small $16 \times 4$ RAM ($k = 4$), a 4-to-16 decoder requires 16 four-input AND gates. This is simple and effective.
- But consider a modest $1\text{K} \times 8$ memory ($k = 10$). A 10-to-1024 decoder requires **1,024 ten-input AND gates**!
- For a $64\text{K}$ memory ($k = 16$), it would require **65,536 sixteen-input gates**.

The routing congestion and silicon area make 1D decoding impossible for large memories.

### 2D (Coincident) Decoding: The Grid Matrix

To solve this scaling bottleneck, commercial RAM chips organize storage cells into a two-dimensional square matrix:

```
                       Column Address (A9..A5)
                                 |
                                 v
                        +-----------------+
                        | 5-to-32 Column  |
                        |     Decoder     |
                        +-----------------+
                                 |
                                 | 32 Column Lines
                                 v
     Row Address       +--------------------+
      (A4..A0)  -----> | 32 x 32 Array      |
                       | of Binary Cells    |
        5-to-32        | (1024 Total Cells) |
      Row Decoder      +--------------------+
                                 |
                                 v
                            Data Output
```

For a 1024-word memory ($k = 10$ address lines):
1. The 10 address bits are split into two 5-bit halves:
   - 5 bits ($A_4 \dots A_0$) drive a **Row Decoder** ($5$-to-$32$), activating one of 32 horizontal word lines.
   - 5 bits ($A_9 \dots A_5$) drive a **Column Decoder** ($5$-to-$32$), activating one of 32 vertical bit lines.
2. A binary storage cell is selected only when **both its row line and column line are active simultaneously** (coincidence selection).
3. **Massive Gate Reduction:**
   - 1D Decoding: 1,024 AND gates (each with 10 inputs).
   - 2D Decoding: $32 + 32 = \mathbf{64}$ AND gates (each with only 5 inputs)!
   The gate count is reduced by over $93\%$.

## Tri-State Logic and Shared System Buses

In a computer, multiple subsystems (RAM, ROM, CPU, disk controllers, network cards) must exchange data over a common set of shared physical wires called the **system data bus**.

If two conventional logic gates were connected to the same wire, and one tried to output logic 1 ($+5\text{ V}$) while the other output logic 0 ($0\text{ V}$), a direct low-resistance short circuit would form. The resulting catastrophic current spike (called **bus contention** or a **bus fight**) would overheat and destroy the semiconductor transistors.

To share a bus safely, circuits use **tri-state buffers** (three-state logic):

```
       Input (A) -----[ > ]-----+----- Output (Y)
                        ^
                        |
                    Enable (EN)
```

A tri-state buffer has three possible electrical output states:
1. **Logic 0:** Low voltage ($0\text{ V}$).
2. **Logic 1:** High voltage ($+3.3\text{ V}$ or $+5\text{ V}$).
3. **High-Impedance ($\text{Hi-Z}$):** The output transistors are completely switched off. The terminal acts as an open circuit (virtual infinite electrical resistance), disconnecting the device from the wire.

When a memory chip is not actively being read, its internal tri-state output buffers are placed in $\text{Hi-Z}$. This allows other chips to transmit data across the shared wires without interference.

## Control Signals and Memory Timing Cycles

Communication between a processor and a RAM chip is governed by three primary active-LOW control signals:
- **/CS (Chip Select) / /CE (Chip Enable):** Enables the chip. When HIGH (1), the chip enters low-power standby and forces all outputs into $\text{Hi-Z}$.
- **/WE (Write Enable):** Commands a Write when LOW (0) and a Read when HIGH (1).
- **/OE (Output Enable):** Controls the tri-state output buffers during a read operation, preventing bus contention during address changes.

```
Read Cycle Timing:
Addresses    ----+=========================+----------------
                 |<----- Access Time t_AA ------>|
                 |                         |
/CS, /OE     ----+-------------------------+----------------
                                           |
Data Out     ------------------------------+======= Valid ==
```

- **Read Access Time ($t_{AA}$):** The maximum time interval from the moment stable addresses appear on the bus until valid data emerges at the data output pins.
- **Write Pulse Width ($t_W$):** The minimum duration /WE must be held LOW to guarantee data is permanently captured by the internal cells.

## Memory Technologies: SRAM vs DRAM vs ROM

| Feature | Static RAM (SRAM) | Dynamic RAM (DRAM) | Read-Only Memory (ROM) |
|:---|:---|:---|:---|
| **Storage Element** | 6-transistor (6T) CMOS bistable latch | 1 transistor + 1 capacitor (1T-1C) | Hardwired diode / transistor matrix |
| **Speed / Access Time** | Extremely fast ($0.5 - 5\text{ ns}$) | Moderate ($10 - 20\text{ ns}$) | Fast ($5 - 15\text{ ns}$) |
| **Silicon Density** | Low (large 6T cell area) | Extremely high (tiny 1T-1C cell) | Very high |
| **Cost per Bit** | High | Very low | Low |
| **Volatility** | Volatile (loses data on power loss) | Volatile (loses data on power loss) | Non-volatile (retains data permanently) |
| **Refresh Needed?** | No refresh required | **Must be refreshed** every $64\text{ ms}$ | No |
| **Primary Use** | CPU L1/L2/L3 caches, register files | Main system memory (DDR4, DDR5) | Boot firmware (BIOS/UEFI), lookup tables |

Because DRAM stores each bit as a microscopic electrostatic charge on a capacitor, that charge leaks away through silicon sub-threshold leakage within milliseconds. A DRAM controller must perform periodic **refresh cycles** (reading and re-amplifying every row thousands of times per second) to preserve stored data.

## Memory Expansion: Combining Smaller Chips

Engineers routinely combine standard commercial memory ICs to build memory modules with larger word sizes or larger address capacities.

### 1. Expanding Word Length (Increasing Bits per Word)

**Objective:** Build a $1\text{K} \times 8$ memory system using two $1\text{K} \times 4$ RAM chips.
- Both chips have 10 address lines ($A_9 \dots A_0$) and 4 data lines.
- **Connection:**
  - Connect all 10 address lines ($A_9 \dots A_0$) in parallel to both chips.
  - Connect the /CS and /WE control lines in parallel to both chips.
  - Split the 8-bit data bus: Chip 0 connects to the lower nibble ($D_3 \dots D_0$), and Chip 1 connects to the upper nibble ($D_7 \dots D_4$).
- Both chips activate at the same address simultaneously, each supplying half of the 8-bit word.

### 2. Expanding Word Capacity (Increasing Number of Words)

**Objective:** Build a $4\text{K} \times 8$ memory system using four $1\text{K} \times 8$ RAM chips.
- A $4\text{K}$ memory requires $2^{12} = 4096$ words $\implies \mathbf{12}$ address lines ($A_{11} \dots A_0$).
- Each $1\text{K}$ chip has only 10 address pins ($A_9 \dots A_0$).
- **Connection:**
  - Lower 10 address lines ($A_9 \dots A_0$) connect in parallel to all four chips.
  - The upper 2 address lines ($A_{11}, A_{10}$) connect to a **2-to-4 decoder**.
  - The four active-LOW outputs of the decoder connect to the active-LOW Chip Select (/CS) pins of the four individual chips:
    - Address range `0x000` to `0x3FF`: Decoder selects Chip 0 (/CS0 = 0).
    - Address range `0x400` to `0x7FF`: Decoder selects Chip 1 (/CS1 = 0).
    - Address range `0x800` to `0xBFF`: Decoder selects Chip 2 (/CS2 = 0).
    - Address range `0xC00` to `0xFFF`: Decoder selects Chip 3 (/CS3 = 0).
  - All four chips connect their 8 data pins directly to the shared 8-bit system data bus ($D_7 \dots D_0$).
  - Because only the single selected chip enables its tri-state buffers, **bus contention is completely avoided**.

```
                           A11, A10 (High Address Bits)
                              |
                              v
                     +-----------------+
                     | 2-to-4 Decoder  |
                     +-----------------+
                       |    |    |    |
           /CS0 -------+    |    |    |
           /CS1 ------------+    |    |
           /CS2 -----------------+    |
           /CS3 ----------------------+
                       |    |    |    |
                       v    v    v    v
                    +----+----+----+----+
                    |RAM0|RAM1|RAM2|RAM3|  (Four 1K x 8 Chips)
                    +----+----+----+----+
                       |    |    |    |
                       +----+----+----+-----> Shared 8-Bit Data Bus (D7..D0)
                       ^
                       |
     A9..A0 -----------+ (Parallel to All Chips)
```

## Common exam pitfalls and student mistakes

When working with computer memory systems, students often make these six mistakes:

1. **Confusing Address Lines ($k$) with Data Lines ($n$) in Capacity Calculations:** Mistaking the number of address lines for total storage capacity. An address bus of $k$ lines addresses $2^k$ distinct memory words, each containing $n$ bits (total capacity $= 2^k \times n$ bits $= \frac{1}{8} \cdot 2^k \times n$ bytes). Confusing bits and bytes is another frequent exam calculation error.
2. **Bus Contention from Overlapping Active Tri-State Drivers:** Failing to guarantee that only one memory chip or peripheral asserts its tri-state drivers onto the shared system data bus at any given instant. If two devices attempt to drive the bus simultaneously with conflicting logic levels (one driving $V_{CC}$ and the other driving GND), a low-impedance short circuit forms, causing heavy shoot-through currents, noise spikes, and hardware damage.
3. **Misinterpreting Active-LOW Control Signal Polarities (/CS, /WE, /OE):** Assuming control inputs are active-HIGH. In real semiconductor memory, /CS (Chip Select), /WE (Write Enable), and /OE (Output Enable) are active-LOW. Leaving /CS tied HIGH (logic 1) places the chip in disabled standby with all outputs clamped in High-Impedance ($\text{Hi-Z}$). Asserting /WE = 0 initiates a Write, whereas /WE = 1 performs a Read.
4. **Incorrect Address Partitioning in Memory Expansion:** When combining multiple $1\text{K} \times 8$ chips to build a $4\text{K} \times 8$ memory, wiring high-order address bits to individual chips and low-order bits to the bank decoder. The lowest $k_{chip}$ address bits ($A_9 \dots A_0$) must connect in parallel to all chips to address internal words, while the highest remaining address bits ($A_{11}, A_{10}$) drive the bank decoder.
5. **Overlooking DRAM Refresh and Destructive Read Characteristics:** Assuming Dynamic RAM (DRAM) retains its stored bits indefinitely like Static RAM (SRAM) as long as power is applied. In DRAM, each 1T-1C cell stores charge on a microscopic capacitor that discharges through semiconductor leakage within milliseconds. DRAM requires periodic refresh cycles, and reading a cell discharges the capacitor, requiring immediate automatic restoration (write-back).
6. **Neglecting External Decoder Propagation Delay in System Access Time:** Assuming the total memory read access time seen by the CPU is simply the chip datasheet access time $t_{AA}$. In modular memory systems, high-order address bits must first propagate through the chip-select decoder ($t_{decoder}$) before the chip is even enabled: the effective system access time is $\max(t_{AA}, t_{decoder} + t_{CO})$.

Design an **$8\text{K} \times 16$** memory system using commercial **$2\text{K} \times 8$** Static RAM chips.
1. How many $2\text{K} \times 8$ chips are required?
2. How many address lines are required for the total $8\text{K}$ memory?
3. How many address lines connect directly to each chip, and how many are used for chip selection?
4. Specify the size of the decoder required to generate the Chip Select signals.
5. Draw the complete interconnection block diagram showing address bus distribution, chip select decoder wiring, and data bus assignments.

<ModelAnswer>
1. **Number of Chips:**
   - Total bits: $8\text{K} \times 16 = 8 \times 1024 \times 16 = 131,072\text{ bits}$.
   - Chip capacity: $2\text{K} \times 8 = 2 \times 1024 \times 8 = 16,384\text{ bits}$.
   - Chips required: $131,072 / 16,384 = 8$ chips.
   - The chips are organized into 4 banks of 2 chips each (each bank provides 16 bits of width).

2. **Total Address Lines:**
   - $8\text{K} = 8 \times 1024 = 8192\text{ words} = 2^{13}$, which requires **13 address lines** ($A_{12} \dots A_0$).

3. **Address Partitioning:**
   - Each $2\text{K} \times 8$ chip has $2048 = 2^{11}$ words, requiring **11 address lines** ($A_{10} \dots A_0$).
   - The lowest 11 address lines ($A_{10} \dots A_0$) connect in parallel to all 8 memory chips.
   - The remaining **2 high-order address lines** ($A_{12}, A_{11}$) are used for bank selection.

4. **Decoder Size:**
   - The 2 high-order address lines ($A_{12}, A_{11}$) drive a **2-to-4 active-LOW decoder**.

   - Output 1 (/Y1) enables Bank 1 (Chips 2 and 3, addresses `0x0800` to `0x0FFF`).
   - Output 2 (/Y2) enables Bank 2 (Chips 4 and 5, addresses `0x1000` to `0x17FF`).
   - Output 3 (/Y3) enables Bank 3 (Chips 6 and 7, addresses `0x1800` to `0x1FFF`).

5. **Data Bus Routing:**
   - In every bank of two chips:
     - The first chip connects to data bus lines $D_7 \dots D_0$ (low byte).
     - The second chip connects to data bus lines $D_{15} \dots D_8$ (high byte).
   - All 4 low-byte chips wire their data pins to $D_7 \dots D_0$, and all 4 high-byte chips wire their data pins to $D_{15} \dots D_8$.
   - /WE connects in parallel to all 8 chips.

A $4096 \times 1$ Static RAM chip uses a 2D coincident decoding array arranged as a $64 \times 64$ matrix of binary cells. Address lines $A_{11} \dots A_6$ connect to a 6-to-64 Row Decoder, and address lines $A_5 \dots A_0$ connect to a 6-to-64 Column Decoder.
Determine which row line and which column line are activated when hexadecimal address $\text{B}37_{16}$ is applied to the chip.

### Problem 3: Static RAM Timing Cycle Verification

A Static RAM chip datasheet specifies the following read timing characteristics:
- Address Access Time: $t_{AA} = 12\text{ ns}$
- Chip Select Access Time: $t_{CO} = 8\text{ ns}$
- Output Enable Access Time: $t_{OE} = 5\text{ ns}$
- Output Hold Time from Address Change: $t_{OH} = 3\text{ ns}$

1. In a synchronous microprocessor bus cycle, addresses are asserted at $t = 0\text{ ns}$, and /CS and /OE are asserted simultaneously at $t = 2\text{ ns}$. At what earliest time is valid data guaranteed to be available on the data bus?
2. What is the absolute minimum bus clock cycle period $T_{cyc}$ if the CPU requires a data setup time of $t_{su(CPU)} = 2.5\text{ ns}$ before the latching clock edge?

<ModelAnswer>
1. **Earliest Valid Data Time:**
   Data becomes valid after the longest of the required access delays:
   - Delay from address valid: $t = 0\text{ ns} + t_{AA} = 0 + 12\text{ ns} = 12\text{ ns}$.
   - Delay from Chip Select: $t = 2\text{ ns} + t_{CO} = 2 + 8\text{ ns} = 10\text{ ns}$.
   - Delay from Output Enable: $t = 2\text{ ns} + t_{OE} = 2 + 5\text{ ns} = 7\text{ ns}$.
   The worst-case bottleneck is the address access time ($t_{AA}$).
   Therefore, valid data is guaranteed at $t = 12\text{ ns}$.

2. **Minimum Bus Clock Cycle Period:**
   The CPU latches data on the clock edge at the end of the bus cycle. Data must be valid at least $t_{su(CPU)}$ prior to that edge:
   $$T_{cyc} \ge t_{valid} + t_{su(CPU)} = 12\text{ ns} + 2.5\text{ ns} = 14.5\text{ ns}$$
   The maximum safe operating bus frequency is:
   $$f_{bus(max)} = 1 / (14.5\text{ ns}) \approx 68.96\text{ MHz}$$
</ModelAnswer>

### Problem 4: 6-Transistor CMOS SRAM Cell Read/Write Stability and Sizing Ratios

A standard CMOS Static RAM (SRAM) cell consists of six transistors: two PMOS pull-up transistors ($P_L, P_R$), two NMOS pull-down driver transistors ($N_L, N_R$), and two NMOS access transistors ($A_L, A_R$) connected to complementary bitlines ($BL, \overline{BL}$) and Wordline ($WL$).
1. Detail the electrical events during a **Read** operation: bitlines precharged to $V_{DD}$, followed by $WL \to 1$. Why does internal storage node $Q$ (holding logic 0) experience a momentary voltage rise ($V_{bump}$)?
2. To prevent this read voltage bump from exceeding the switching threshold of the opposing inverter and accidentally flipping the stored bit (read disturb), what transistor width-to-length ratio constraint (the **cell ratio** $\beta$) must be enforced between driver $N_L$ and access transistor $A_L$?
3. Detail the electrical events during a **Write** operation: strong write drivers pull $BL \to 0$ while $WL \to 1$. What transistor sizing ratio (the **pull-up ratio** $\gamma$) between access transistor $A_R$ and PMOS pull-up $P_R$ is required to force a node holding 1 down to 0?

<ModelAnswer>
1. **Read Operation and Node Voltage Bump ($V_{bump}$):**
   - Prior to read, both bitlines ($BL$ and $\overline{BL}$) are precharged to $V_{DD}$ and then floated.
   - When Wordline rises ($WL = V_{DD}$), access transistors $A_L$ and $A_R$ turn ON.
   - Suppose the cell stores $Q = 0$ (at $0\text{ V}$) and $Q' = 1$ (at $V_{DD}$).
   - On the left side, bitline $BL$ sits at $V_{DD}$ while node $Q$ is at $0\text{ V}$. Current flows from the precharged bitline through access transistor $A_L$ and pull-down NMOS driver $N_L$ to ground.
   - Because both $A_L$ and $N_L$ have finite on-resistances ($R_{A_L}$ and $R_{N_L}$), they form a resistive voltage divider between $V_{DD}$ and GND.
   - Internal node $Q$ rises to an intermediate voltage:
     $$V_{bump} = V_{DD} \cdot \frac{R_{N_L}}{R_{A_L} + R_{N_L}}$$
   - On the right side ($Q' = V_{DD}, \overline{BL} = V_{DD}$), no current flows because both nodes are at the same potential.

2. **Read Stability Constraint (Cell Ratio $\beta$):**
   - If $V_{bump}$ rises above the threshold voltage $V_{th(N_R)}$ of the opposing NMOS driver $N_R$, $N_R$ will turn ON, discharging $Q'$ and accidentally flipping the stored bit!
   - To keep $V_{bump}$ safely below $V_{th}$, driver transistor $N_L$ must have much lower resistance than access transistor $A_L$.
   - Lower resistance requires a wider channel: the **cell ratio** is defined as:
     $$\beta = \frac{(W/L)_{driver}}{(W/L)_{access}} = \frac{(W/L)_{N_L}}{(W/L)_{A_L}} \ge 1.2 \text{ to } 1.5$$
   - The pull-down NMOS driver must be physically wider (stronger) than the access transistor.

3. **Write Operation and Pull-Up Sizing Ratio ($\gamma$):**
   - To write a 0 into a node holding 1 ($Q' = 1$), the external write driver connects bitline $\overline{BL}$ solidly to ground ($0\text{ V}$).
   - When $WL = V_{DD}$, access transistor $A_R$ turns ON, forming a voltage divider between the PMOS pull-up $P_R$ (connected to $V_{DD}$) and $\overline{BL}$ (connected to $0\text{ V}$).
   - To flip the cross-coupled inverters, access transistor $A_R$ must pull node $Q'$ down below the inverter threshold voltage $V_{th}$.
   - Therefore, access transistor $A_R$ must be **stronger than the PMOS pull-up transistor $P_R$**:
     $$\gamma = \frac{(W/L)_{pull-up}}{(W/L)_{access}} = \frac{(W/L)_{P_R}}{(W/L)_{A_R}} \le 0.6 \text{ to } 0.8$$
   - Transistor sizing hierarchy in a 6T SRAM cell:
     $$\mathbf{W_{driver} \gt W_{access} \gt W_{pull-up}}$$
</ModelAnswer>

### Problem 5: Dynamic RAM (DRAM) Refresh Overhead and Bandwidth Loss

A 1-gigabit ($1\text{ Gb}$) Dynamic RAM (DRAM) chip contains 8192 memory rows ($2^{13}$ rows). The microscopic cell storage capacitors exhibit semiconductor leakage, requiring every row in the memory array to be refreshed at least once every $64\text{ ms}$ to avoid data loss.
Each row refresh cycle requires $t_{RC} = 45\text{ ns}$ (Row Cycle Time), during which the memory array cannot service processor read or write requests.
1. Calculate the total time in microseconds spent performing refresh cycles during each $64\text{ ms}$ interval.
2. Determine the percentage of memory bandwidth lost to DRAM refresh overhead.
3. Compare "burst refresh" against "distributed refresh" architectures in memory controllers.

<ModelAnswer>
1. **Total Refresh Time per Interval:**
   All 8192 rows must be refreshed within $64\text{ ms}$:
   $$t_{refresh(total)} = N_{rows} \times t_{RC} = 8192 \times 45\text{ ns} = 368,640\text{ ns} \approx 368.64\ \mu\text{s}$$

2. **Bandwidth Loss Percentage:**
   The total available time window is $64\text{ ms} = 64,000\ \mu\text{s}$:
   $$\text{Overhead} = \frac{t_{refresh(total)}}{T_{interval}} \times 100\% = \frac{368.64\ \mu\text{s}}{64,000\ \mu\text{s}} \times 100\% = 0.576\%$$
   Less than $0.6\%$ of memory bandwidth is consumed by refresh, leaving over $99.4\%$ available for processor execution.

3. **Burst Refresh vs Distributed Refresh:**
   - **Burst Refresh:** The memory controller halts all CPU memory access and performs all 8192 row refresh cycles back-to-back in one unbroken block ($368.64\ \mu\text{s}$).
     - *Disadvantage:* Freezes the CPU for over 360 microseconds, making it completely unsuitable for real-time systems, audio/video streaming, or interrupt-driven computing.
   - **Distributed Refresh:** The controller spaces the 8192 refresh cycles evenly across the $64\text{ ms}$ window:
     $$T_{interval} = \frac{64\text{ ms}}{8192} = 7.8125\ \mu\text{s}$$
     Every $7.81\ \mu\text{s}$, a timer triggers the refresh of exactly one row ($45\text{ ns}$ interruption).
     - *Advantage:* Latency is negligible, ensuring smooth CPU execution without long pauses.
</ModelAnswer>

### Problem 6: Bidirectional Tri-State Bus Transceiver Interface (74LS245)

A memory board containing $4\text{KB}$ of Static RAM (address range `0x8000` to `0x8FFF`) interfaces to a shared 8-bit system data bus ($D_7..D_0$) through an industry-standard **74LS245** octal bus transceiver.
The 74LS245 has two control pins:
- $\overline{OE}$ (Output Enable): active-LOW. When 0, the transceiver drivers are active; when 1, both sides are placed in High-Impedance ($\text{Hi-Z}$).
- $DIR$ (Direction): when 1, data flows $A \to B$ (Board to System Bus, Read); when 0, data flows $B \to A$ (System Bus to Board, Write).

The microprocessor bus provides:
- 16 address lines ($A_{15}..A_0$)
- Active-LOW Memory Request ($\overline{MREQ}$)
- Active-LOW Read control ($\overline{RD}$)
- Active-LOW Write control ($\overline{WR}$)

1. Design the address decoding logic that detects the memory board's address space (`0x8000`–`0x8FFF`).
2. Derive the Boolean equations for $\overline{OE}$ and $DIR$ of the 74LS245 transceiver.
3. Explain why bus transceiver disable timing ($t_{disable}$) must be strictly faster than enable timing ($t_{enable}$) to prevent bus contention during bus turnaround.

<ModelAnswer>
1. **Address Space Decoding (`0x8000` to `0x8FFF`):**
   - Address `0x8000` to `0x8FFF` in binary:
     - `0x8000` = $1000\ 0000\ 0000\ 0000_2$
     - `0x8FFF` = $1000\ 1111\ 1111\ 1111_2$
   - The lower 12 address lines ($A_{11} \dots A_0$) address the internal $4096 = 2^{12}$ bytes.
   - The upper 4 address lines must match $1000_2$:
     $$A_{15} = 1, \quad A_{14} = 0, \quad A_{13} = 0, \quad A_{12} = 0$$
   - Board Select signal:
     $$\text{BoardSelect} = A_{15} \cdot A_{14}' \cdot A_{13}' \cdot A_{12}' \cdot \overline{MREQ}'$$

2. **Control Equations for 74LS245 Transceiver:**
   - **Direction ($DIR$):** $DIR = 1$ when the CPU is reading from the board (Board to System Bus).
     $$DIR = \overline{RD}'$$
     (When $\overline{RD} = 0$, $DIR = 1$; during write $\overline{WR} = 0$, $DIR = 0$).
   - **Output Enable ($\overline{OE}$):** The transceiver must be enabled (assert $\overline{OE} = 0$) ONLY when this board is addressed AND a valid read or write memory cycle is active:
     $$\text{ActiveAccess} = \text{BoardSelect} \cdot (\overline{RD}' + \overline{WR}')$$
     Because $\overline{OE}$ is active-LOW:
     $$\overline{OE} = \text{ActiveAccess}' = (\text{BoardSelect} \cdot (\overline{RD}' + \overline{WR}'))'$$
   - Whenever the board is unselected or the bus is idle, $\overline{OE} = 1$, isolating the board's internal data bus from the system data bus in High-Impedance ($\text{Hi-Z}$).

3. **Bus Turnaround and Contention Prevention ($t_{disable} \lt t_{enable}$):**
   - When a bus read ends and a write begins (or when the CPU switches from reading Memory to reading I/O), the currently driving device must disconnect its drivers from the bus.
   - If the previous device's turn-off delay ($t_{disable}$) is slower than the new device's turn-on delay ($t_{enable}$), both devices will drive the bus simultaneously for a fraction of a nanosecond.
   - If one device outputs $V_{CC}$ (1) while the other outputs GND (0), a short circuit occurs, producing severe voltage dips on power rails, ground bounce, and damaging shoot-through currents.
   - High-reliability bus transceivers are silicon-engineered to guarantee **break-before-make** switching ($t_{disable} \lt t_{enable}$).
</ModelAnswer>
